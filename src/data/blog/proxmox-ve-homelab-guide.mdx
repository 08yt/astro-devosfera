买来 Intel N100、J4125 或 AMD 锐龙迷你小主机后，很多朋友直接安装了 Windows。

然而 Windows 系统不仅资源开销巨大，而且偶发的强制更新重启常导致部署在后台的 NAS 存储、下载机或 Sing-box 透明网关瞬间瘫痪。若物理机直装单一 Linux，一旦配置失误便不得不接显示器重装，代价沉重。

**Proxmox VE (PVE)** 作为基于 Debian Linux 的开源 Type-1（裸金属）Hypervisor 虚拟化系统，兼具 KVM 全虚拟化与 LXC 极轻量容器，是打造家庭“All in One”私有云数据中心的无冕之王！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
> - **裸金属虚拟化优势**：直接运行于物理硬件之上，相比 ESXi 更加开放灵活，支持 Debian 原生生态、ZFS 存储池与全功能 Linux 驱动。
> - **秒级时光机快照**：配置网络或更新前打一个 Snapshot，折腾翻车仅需 3 秒即可一键回滚如初。
> - **PCIe 硬件直通 (IOMMU Passthrough)**：可将特定网口、SATA 控制器或 Intel 核显无损“透传”给虚拟机，获得 99%+ 的原生硬件性能。
> - **开箱换源调优**：PVE 8 安装后一键去除企业订阅弹窗，换为国内清华/中科大开源镜像源，开启 CPU 动态调频降低发热。

## 🛠️ 2026 生产级 PVE 安装与硬件要求

### 1. BIOS 关键设置（开机狂按 F2 / Delete）
- 开启 **VT-x / AMD-V**（CPU 硬件虚拟化支持）。
- 开启 **VT-d / AMD IOMMU**（硬件直通必备）。
- 关闭 **Secure Boot**（安全启动）。
- 开启 **AC Recovery (Power On)**：来电自动开机，断电恢复后无需手动按开机键。

### 2. 网络规划与安装参数
- 使用 Rufus 或 balenaEtcher 将 PVE 8.x ISO 写入 U 盘。
- 安装向导中分配固定静态 IP（如主路由为 `192.168.1.1`，PVE 设为 `192.168.1.100`，网关指向 `192.168.1.1`）。

## 🚀 PVE 8 装机必备三大优化脚本

在主力机浏览器打开 `https://192.168.1.100:8006`，使用 `root` 登录控制台，进入 Shell 执行：

### 1. 切换国内开源软件源并去除企业订阅弹窗
```bash
# 禁用官方企业商业源
sed -Ezi.bak "s/(<tbody class=\"x-grid-body\">)/<!--\1-->/" /usr/share/javascript/proxmox-widget-toolkit/proxmoxlib.js
rm -f /etc/apt/sources.list.d/pve-enterprise.list

# 添加国内无订阅开源源
echo "deb https://mirrors.ustc.edu.cn/proxmox/debian/pve bookworm pve-no-subscription" > /etc/apt/sources.list.d/pve-no-subscription.list
apt update
```

### 2. 开启 PCIe / IOMMU 硬件直通支持
编辑 `/etc/default/grub`：
```bash
# Intel CPU 添加 intel_iommu=on iommu=pt；AMD CPU 添加 amd_iommu=on iommu=pt
GRUB_CMDLINE_LINUX_DEFAULT="quiet intel_iommu=on iommu=pt"
```
更新 grub 并重启：`update-grub && reboot`。

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: PVE 里的虚拟机（VM）与 LXC 容器有什么本质区别？
**答**：KVM 虚拟机（VM）模拟完整虚拟硬件，支持运行 Windows、OpenWrt、iKuai；而 LXC 容器与宿主机共享 Linux 内核，开机仅需 1 秒且内存开销不足 30MB，适合跑 Docker、Nginx 或数据库。

### Q2: 自建 PVE 节点出海拉取镜像选哪家海外 VPS 最快？
