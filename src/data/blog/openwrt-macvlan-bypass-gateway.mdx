很多玩家在折腾家庭透明代理或科学上网时，受限于主硬路由的微弱性能，常买一台单网口小主机（如 N1 盒子、树莓派或迷你主机），刷入 OpenWrt 作为**旁路由（旁路网关）**。

但在配置完成后，常常遇到几大头疼痛点：

1. **内网局域网测速腰斩**：局域网手机访问 NAS 拷贝文件，千兆跑不满，仅剩三四百兆。
2. **发卡弯（Hairpin）与软中断吞噬 CPU**：进出流量全挤在同一张单网口上反复进出，CPU 软中断直接打满。
3. **主路由与旁路由死锁**：一旦旁路由维护重启，全家断网。

本文将从底层解构单网口旁路由的流量回路，并教你使用 **Linux Macvlan 驱动** 打造轻量、隔离且绝不拖垮主网的生产级旁路网关！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **发卡弯（Hairpin）根源**：单网口旁路由同时处理接收与转发，单根网线双向跑满千兆导致物理带宽减半；若滥用 SNAT，内网设备真实 IP 全部丢失。
> - **Macvlan 核心价值**：在单张物理网卡上虚拟出具备专属独立 MAC 地址的二层网卡，以原生平级实体接入局域网，与主路由无缝协同。
> - **Docker 旁路由最佳形态**：主物理机保留系统纯净，通过 Docker + Macvlan 容器化常驻 OpenWrt，资源开销不足 50MB。

## 🛠️ 2026 生产级 Docker + Macvlan OpenWrt 部署实战

### 第一步：开启宿主机网卡混杂模式 (Promiscuous Mode)

在宿主机终端执行：

```bash
# 假设物理有线网卡名为 eth0
sudo ip link set eth0 promisc on

# 设置开机自动开启混杂模式
sudo tee -a /etc/network/interfaces <<EOF
up ip link set eth0 promisc on
EOF
```

### 第二步：创建 Docker Macvlan 专用子网

```bash
docker network create -d macvlan \
  --subnet=192.168.1.0/24 \
  --gateway=192.168.1.1 \
  --ip-range=192.168.1.200/29 \
  -o parent=eth0 \
  macvlan_net
```

### 第三步：拉取并启动 OpenWrt 容器

```bash
docker run -d \
  --name openwrt_gateway \
  --restart unless-stopped \
  --network macvlan_net \
  --ip 192.168.1.2 \
  --privileged \
  sulinggg/openwrt:latest /sbin/init
```

## ⚙️ OpenWrt 旁路由三大黄金设置法则

1. **彻底关闭 DHCP**：进入 OpenWrt“网络 -> 接口 -> LAN -> 高级设置”，勾选 **忽略此接口 (不在此接口提供 DHCP 服务)**，全屋 DHCP 仅保留给主路由，防止网络大混乱。
2. **设置静态网关与 DNS**：
   - LAN 接口 IP：`192.168.1.2`
   - IPv4 网关：指向主路由 `192.168.1.1`
   - 自定义 DNS：填入主路由 `192.168.1.1` 或阿里/腾讯公共 DoH。
3. **修复数据包不对称问题**：在“网络 -> 防火墙 -> 自定义规则”添加：
   ```bash
   iptables -t nat -I POSTROUTING -o eth0 -j MASQUERADE
   ```

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 怎样做到家属手机正常直连，极客设备才走旁路网关？

**答**：主路由 DHCP 默认下发的网关依然为 `192.168.1.1`；仅在 Apple TV、个人电脑或手机的 Wi-Fi 设置中，将网关和 DNS 手动改为 `192.168.1.2`。即使旁路由关机重启，普通家属上网也完全不受任何影响。

### Q2: 旁路网关出海搭配哪种海外 VPS 体验最佳？

**答**：在自建 **DMIT** 或 **搬瓦工** 的 **中国电信 CN2 GIA** 或 **联通 AS9929** 专线 VPS 上，配合旁路网关的 Sing-box 透明代理，能实现全屋极速秒开。选购参考见 [《2026 国外 VPS 选购指南》](/posts/vps-buying-guide-2026/)。
