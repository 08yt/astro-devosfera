在科学上网进阶后，很多玩家都不再满足于单一节点。你可能同时拥有专打游戏的香港 CN2 节点、专门解封 Netflix 的美国家宽节点以及备用的日本 AS9929 节点。

在 **Sing-box** 中，通过强大的 **outbounds (出站组)** 配合 `selector` 与 `urltest` 能够实现无感高可用故障转移！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **`selector` (手动选择器)**：提供 UI 列表或 JSON 总闸，允许手动干预切换出站（相当于 Clash 的 select）。
> - **`urltest` (自动测速选择)**：后台定期静默测试节点延迟（如每 3 分钟 `interval: "3m"`），自动将流量切换至速度最快的节点。
> - **`tolerance` 容忍度**：强烈建议设为 `50`（单位 ms）。若当前节点仅比最快节点慢不足 50ms 则不盲目频繁切换，避免游戏断连或 IP 漂移导致网页重新登录。

---

## 🛠️ 2026 高可用容灾出站 JSON 模板

在 Sing-box 客户端 `config.json` 的 `outbounds` 中配置分层管理：

```json
{
  "outbounds": [
    {
      "type": "selector",
      "tag": "Proxy-Selector",
      "outbounds": ["Auto-Fastest", "HK-CN2-Gaming", "US-Netflix", "direct"],
      "default": "Auto-Fastest"
    },
    {
      "type": "urltest",
      "tag": "Auto-Fastest",
      "outbounds": ["HK-CN2-Gaming", "US-Netflix", "JP-AS9929"],
      "url": "https://www.gstatic.com/generate_204",
      "interval": "3m",
      "tolerance": 50
    },
    {
      "type": "vless",
      "tag": "HK-CN2-Gaming"
    },
    {
      "type": "hysteria2",
      "tag": "US-Netflix"
    },
    {
      "type": "direct",
      "tag": "direct"
    }
  ]
}
```

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 为什么 `urltest` 频繁切换节点会导致游戏掉线？

**答**：这是因为把 `tolerance` 容忍度设为了 `0`。节点延迟时刻微小波动，设为 `0` 会导致 TCP Socket 连接因为公网出口 IP 变动而被切断。保持 `tolerance: 50` 可以在稳定与低延迟间达到最佳平衡。

### Q2: 自建 VPS 节点配合机场节点做 `urltest` 容灾效果好吗？

**答**：非常理想！主节点使用 **DMIT** 或 **搬瓦工** 的 **中国电信 CN2 GIA** 直连 VPS，备用节点绑定商业机场，当自建 VPS 维护或公网丢包时，Sing-box 会在 3 分钟内静默无感切换至备用专线。
