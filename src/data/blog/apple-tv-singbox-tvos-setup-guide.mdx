自从苹果发布 tvOS 17 与 18 之后，系统底层正式开放了原生网络 Extension 框架。

这意味你不再需要繁琐的旁路由或软路由，**直接在 Apple TV 盒子上即可运行原生 Sing-box (SFI) 客户端**！大屏幕上的 Netflix 4K、YouTube 视频与 Disney+ 迎来真正的“即插即用”时代。

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **免硬件旁路由**：基于 tvOS 原生 Network Extension，低功耗常驻后台，支持开机自动接管分流。
> - **iCloud 极速同步**：在 iPhone 端导入 Sing-box 订阅后，通过同一 Apple ID 即可无感自动静默同步至 Apple TV 客户端。
> - **2026 规则分流**：路由使用二进制 `.srs` 规则集匹配 `geosite-netflix` 与 `geosite-youtube`。

## 📺 为什么选择 tvOS 原生 SFI 客户端？

相比传统的软路由/旁路由配置：

- **零额外硬件开销**：无需配置 N1 或软路由盒子，避免全家网关被拖累。
- **4K/8K 极限吞吐**：直接发挥 Apple TV A15 芯片的硬件解密性能，轻松跑满千兆带宽。
- **后台常驻不掉线**：系统原生支持，休眠唤醒即刻连接。

## 📥 订阅导入与 iCloud 云同步

### 方案 A：iCloud 静默同步（最优雅）

1. 在 iPhone 安装官方 **Sing-box** 客户端。
2. 导入机场提供的 Sing-box JSON 订阅。
3. 确保 iPhone 与 Apple TV 登录同一 iCloud 账号并开启云同步，配置瞬间自动同步至电视端！

### 方案 B：局域网 Web 控制台导入

1. 在 Apple TV 打开 SFI，开启 `Remote Dashboard`。
2. 在电脑/手机浏览器访问屏幕显示的 IP 地址（如 `http://192.168.1.15:9090`），直接上传 `config.json`。

## ⚙️ 2026 大屏 4K 流媒体分流模板

在服务端的 `route` 模块中配置精细分流：

```json
{
  "route": {
    "rule_set": [
      {
        "tag": "geosite-netflix",
        "type": "remote",
        "format": "binary",
        "url": "https://raw.githubusercontent.com/SagerNet/sing-geosite/rule-set/geosite-netflix.srs"
      }
    ],
    "rules": [
      {
        "rule_set": ["geosite-netflix"],
        "outbound": "🎬 流媒体解锁组"
      },
      {
        "geoip": ["private"],
        "outbound": "direct"
      }
    ],
    "final": "🚀 默认节点"
  }
}
```

> [!IMPORTANT]
> **HomeKit 防阻断**：必须在直连规则中包含 `"geoip": ["private"]`，防止 Apple TV 拦截 HomePod 或 NAS 局域网广播流量。

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: Apple TV 上看 Netflix 提示“使用代理/解封程序”怎么办？

**答**：Netflix 对机房 IP 风控严格。建议在 `outbounds` 中配置绑定 **中国电信 CN2 GIA** 或 **移动 CMIN2** 回程的原生家宽 IP 节点，或通过 WARP 链式代理智能解锁。

### Q2: 息屏休眠后再开机，Sing-box 需要手动重新连接吗？

**答**：不需要。SFI 接入 tvOS 系统级 Network Extension，开机即自动唤醒后台常驻。
