在接触科学上网、家庭网络改造与 Homelab 时，很多人常有疑问：
**“家里明明已经有数百元的商用 Wi-Fi 路由器，为什么还要折腾软路由与 OpenWrt？”**

商用“硬路由”受限于成本，处理器算力微弱且固件封闭；一旦开启加密解密、多路流媒体并发分流或内网去广告，CPU 负载瞬间打满导致断流降速。

**软路由（基于通用 x86 / ARM 架构小主机运行 OpenWrt 等定制 Linux 系统的路由器）** 凭借桌面级处理器的强悍算力与开放的开源生态，成为了家庭网络的终极中枢！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **硬路由 vs 软路由**：硬路由胜在天线射频与 Wi-Fi 覆盖；软路由拥有 x86（如 Intel N100）数倍于硬路由的计算性能，专精复杂加密分流、DNS 防污染与全屋插件服务。
> - **最佳实战架构：旁路网关（旁路由模式）**：原有硬路由负责光猫拨号与 Wi-Fi 发射，软路由作为内网网关分担 Sing-box 透明代理与广告拦截；即便软路由调试重启，全屋基础网络与家属上网不受任何影响。
> - **OpenWrt 的地位**：基于 Linux 内核专为网络路由优化的开源操作系统，掌握 nftables/iptables 防火墙、TProxy/TUN 透明代理与 Docker 扩展。

## 🌐 2026 最优网络拓扑：旁路由（旁路网关）模式

新手切忌盲目追求“All in One 单臂主路由”造成全家断网矛盾；强烈推荐**旁路由双机协同方案**：

```mermaid
graph TD
    Modem[光猫 (桥接模式)] --> MainRouter[主硬路由 (负责 PPPoE 拨号 + DHCP + AP Wi-Fi)]
    MainRouter <== LAN 千兆网线 ==> SoftRouter[旁路由 OpenWrt (192.168.1.2: Sing-box/AdGuard)]
    MainRouter -. 无线 Wi-Fi .-> NormalDev[普通家庭设备 (网关指向 192.168.1.1, 直连公网)]
    MainRouter -. 无线/有线 .-> GeekDev[极客设备/Apple TV (网关手动设为 192.168.1.2, 无感出海)]
```

### 旁路由配置核心两步：

1. **设置旁路由静态 IP**：
   - 旁路由 IP 设为主路由同网段静态地址（如 `192.168.1.2`）。
   - 旁路由的默认网关和 DNS 均填入主路由 IP（`192.168.1.1`）。
   - **务必关闭旁路由的 DHCP 服务**，防止与主路由冲突。
2. **设备按需走旁路网关**：
   - 需要免客户端无感科学上网的设备（如 Apple TV / 智能电视 / 手机），在设备网络设置中将**网关与 DNS 手动改为 `192.168.1.2`** 即可！

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 旁路由模式经常出现网络变慢或单向通信是何原因？

**答**：通常是因为防火墙未开启 NAT 伪装；在 OpenWrt 的“网络 -> 防火墙 -> 自定义规则”中添加一行 `iptables -t nat -I POSTROUTING -o br-lan -j MASQUERADE` 即可解决网络数据包回源不对称问题。
