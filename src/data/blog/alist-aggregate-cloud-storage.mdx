很多极客玩 Homelab 的一大动力，就是搭建属于自己的私人流媒体影视海报墙（Jellyfin / Emby / Plex / Infuse）。

但动辄几十 TB 的原盘 4K 电影面临着巨大的硬件门槛 ── **机械硬盘昂贵、噪音大且功耗高**。

**Alist** 彻底颠覆了这一切 ── 它是一个支持全平台多网盘聚合的协议网关，能将阿里云盘、百度网盘、115、123 云盘、Google Drive、OneDrive 等数十种大厂网盘聚合为统一的 **WebDAV 标准协议**，让播放器直接将云端网盘当成本地硬盘读取！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **核心机制**：Alist 作为多网盘统一中转网关，将各大网盘私有 API 转化为标准的 WebDAV 协议。
> - **零硬盘成本**：Jellyfin / Infuse / 电视盒子通过 WebDAV 挂载 Alist，实现原画 4K 蓝光流媒体直连播放（流量由网盘 CDN 直接下发，不占宿主机带宽）。
> - **一键部署**：通过 Docker Compose 单一容器几秒启动，支持本地 SQLite / MySQL 存储元数据。

## 🛠️ 2026 生产级 Docker Compose 部署配置

在服务器创建 `compose.yaml`：

```yaml
services:
  alist:
    image: xhofe/alist:latest
    container_name: alist
    restart: unless-stopped
    ports:
      - "5244:5244"
    volumes:
      - ./data:/opt/alist/data
    environment:
      - PUID=0
      - PGID=0
      - UMASK=022
```

启动并查看初始管理员密码：

```bash
docker compose up -d
docker exec -it alist ./alist admin
```

## 🎬 零本地存储观影：Alist + WebDAV + Jellyfin / Infuse

1. **登录 Alist 后台 (`http://IP:5244`)**：进入“存储”添加网盘账号（如阿里云盘 Open API / 百度网盘 / 115 网盘）。
2. **在 Apple TV / 电视端打开 Infuse 或在服务器打开 Jellyfin**：
   - 添加数据源：选择 **WebDAV** 协议。
   - 服务器地址：`http://你的Alist地址:5244/dav`
   - 路径：填写挂载网盘的根路径（如 `/aliyun`）。
3. **享受 100TB 4K 蓝光极速流媒体**：Alist 会将真实下载地址 302 重定向给客户端，直接享受大厂云盘千兆 CDN 下行，无本地硬盘损耗！

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 播放 4K 蓝光视频时 Alist 服务器会消耗流量吗？

**答**：在 Alist 存储设置中开启“302 重定向（Native）”模式后，视频流是由网盘 CDN 服务器直接发往你的播放器（Infuse/Jellyfin），Alist 宿主机只转发元数据，几乎不消耗 VPS 流量。

### Q2: 配合自建海外 VPS 搭建 Alist 选哪家网络线路最好？

**答**：挂载 Google Drive / OneDrive 等海外网盘时，在 **DMIT** 或 **搬瓦工** 的 **中国电信 CN2 GIA** 或 **联通 AS9929** 专线 VPS 上能获得最佳的 API 响应与极速刮削。选购参考见 [《2026 国外 VPS 选购指南》](/posts/vps-buying-guide-2026/)。
