基础教程跑通之后，这篇讲进阶：多订阅、内核管理，以及群里天天有人问的翻车现场。

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **多订阅**：工作/生活/备用分开，节点分组命名加前缀（如 `[美]CN2-01`）。
> - **内核切换**：尝鲜新版前备份配置，翻车一键回滚。
> - **排错三板斧**：看日志 → 二分法关规则 → 换个网络环境试。

## 📚 1. 多订阅管理

节点一多就乱，三个习惯：

1. **分组**：按用途建订阅组——主力机场、备用机场、自建节点，故障时一键切换整组。
2. **命名**：节点名加前缀，如 `[HK]家宽-01`、`[US]CN2-02`，列表里一眼定位。
3. **自动更新**：每组设不同更新间隔（主力 12h、备用 24h），避免同时刷新全挂。

订阅链接是敏感信息，别截图发群（Token 泄露会被盗刷流量）。

## 🔧 2. 内核版本管理

图形客户端一般允许切换 sing-box 内核版本：

- **跟随稳定版**：日常用客户端默认的内核，最省心；
- **尝鲜新版**：新版本新特性想试？先备份配置再切，`sing-box check` 过一遍；
- **回滚**：新版翻车（某协议连不上），切回旧内核+旧配置，5 分钟复活。

**铁律**：升级内核前，先看官方迁移文档的废弃表，确认配置兼容。

## 🚨 3. 十大翻车现场排错

### ① 订阅更新后节点全红
订阅过期或被重置 → 机场后台复制新链接；检查本地时间（TLS 对时间敏感，差几分钟就握手失败）。

### ② TUN 开启后打不开网页
大概率 DNS 问题：切 TUN DNS 接管模式（sing-box-windows）或检查 `hijack-dns` 规则；再看 FakeIP 有没有把 DNS 吃掉。

### ③ 只有 Telegram 能连，网页打不开
分流规则问题：`final` 被设成 direct 了，或 geoip 规则集没下载成功。

### ④ 延迟突然暴涨
先测速换节点；再看是不是晚高峰（CN2 也扛不住春晚级拥堵）；直连 VPS 用户检查 BBR 是否还在。

### ⑤ 客户端闪退/无法启动
99% 是配置文件 JSON 写错：用在线 JSON 校验器过一遍，或 `sing-box check` 定位行号。

### ⑥ 订阅链接粘贴后没反应
Clash 订阅直接粘给原生客户端 → 先转换（见 [《订阅转换总纲》](/posts/convert-clash-to-singbox/)）。

### ⑦ 切换节点后还是慢
DNS 缓存/连接复用：重启客户端清掉旧连接；检查是不是规则把流量送进了慢节点组。

### ⑧ 公司内网/校园网连不上
TUN 劫持了内网流量 → 局域网豁免（`192.168.0.0/16`、`10.0.0.0/8` → direct）；或内网环境切回系统代理模式。

### ⑨ macOS 大版本升级后配置丢失
官方偶尔更换开发者账号导致应用变更新包，升级前先备份，丢了按 [《SFM macOS 篇》](/posts/sing-box-macos-sfm-guide/) 的迁移思路恢复。

### ⑩ 流量跑得飞快但没用代理
检查系统代理/TUN 是否真的开启；iOS 上看状态栏 VPN 图标；桌面端看客户端状态页的"已代理流量"计数。

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 排错时日志看不懂怎么办？

**答**：抓关键词：`FATAL`（启动失败，看上一行）、`deprecated`（字段废弃，对照迁移指南改）、`timeout`（网络问题，换节点）、`handshake failure`（TLS/Reality 参数错）。

### Q2: 多个客户端（手机+电脑）共用订阅会怎样？

**答**：看机场规则：有的限在线设备数，多端同时在线会被封。备用方案是自建节点，不限设备。
