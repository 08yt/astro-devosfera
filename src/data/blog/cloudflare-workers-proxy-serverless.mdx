很多学生党或轻度用户面临的痛点是：每个月买 VPS 花费不菲，且遇到 IP 封锁时更换 IP 成本昂贵。

利用 Cloudflare 的全球边缘 Serverless 函数计算服务 **Workers**，我们可以将一段轻量 VLESS 代理逻辑代码部署在其 200+ 城市的节点上，实现零成本、永不封锁的免费代理！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **Serverless 优势**：无需购买 Linux VPS，节点寄生在 Cloudflare CDN 边缘集群上，天然免疫 IP 封锁。
> - **协议与伪装**：采用 **VLESS + WebSocket (WS)** 或 **gRPC** 传输层，配合 UUID 秘钥鉴权。
> - **速度优化（关键）**：默认 `workers.dev` 域名在晚高峰可能受到国内骨干网 QoS 限速，必须配合 **Cloudflare 优选 IP**（Clean IP）达到秒开 4K。

---

## 🛠️ 1. 创建 Cloudflare Workers 项目

1. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)，在左侧进入 **Workers & Pages** -> 点击 **Create Application**。
2. 创建项目并点击 **Edit code**（网页在线代码编辑器）。

---

## 🐍 2. 部署 VLESS 核心代码与配置 UUID

在编辑器中注入开源 VLESS 代理逻辑脚本，并在顶部替换你专属的 **UUID**：

```javascript
// Worker JS 片段范例
const userID = "your-generated-uuid-here";
const proxyIP = "1.1.1.1"; // 可选指定优选中转出站 IP

export default {
  async fetch(request, env) {
    // 监听 WebSocket 连接并解密 VLESS 标头
  },
};
```

点击 **Save and Deploy**，获取专属域名 `https://my-proxy.yourname.workers.dev`。

---

## 📱 3. 在 Sing-box 中接入 Workers 节点

在 Sing-box 客户端 `outbounds` 配置中填入：

```json
{
  "type": "vless",
  "tag": "cf-workers-node",
  "server": "104.16.1.1", // 填入测速筛选出的 Cloudflare 优选 IP
  "server_port": 443,
  "uuid": "your-generated-uuid-here",
  "tls": {
    "enabled": true,
    "server_name": "my-proxy.yourname.workers.dev"
  },
  "transport": {
    "type": "ws",
    "path": "/?ed=2048",
    "headers": {
      "Host": "my-proxy.yourname.workers.dev"
    }
  }
}
```

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: Cloudflare Workers 免费版每天有使用次数限制吗？

**答**：免费版 Workers 每天提供 100,000 次 Request 免费额度。对于个人日常网页浏览和观看视频完全足够。

### Q2: 为什么使用 Workers 节点提示无法打开 Netflix 或 OpenAI？

**答**：Cloudflare 边缘 IP 会被 OpenAI 及部分流媒体识别为 Cloud Data Center 数据中心流量。如需原生解锁，建议使用 **DMIT** 或 **搬瓦工** 等拥有原生家宽/CN2 GIA 的商业 VPS，或结合 WARP 智能分流。
