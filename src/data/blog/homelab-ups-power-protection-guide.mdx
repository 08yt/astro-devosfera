在 Homelab 圈子里有一句无数硬盘报废换来的至理名言：**“不上 UPS 的存储服务器，就是在裸奔。”**

许多朋友斥资上万元组装了多盘位 NAS、万兆软路由与 PVE 虚拟化主机，配了坚固的 RAID-Z2 阵列，以为万事大吉。

然而一次突如其来的雷雨天停电，高速运转的机械硬盘由于瞬间失电导致磁头直接拍击在盘片上（磁头划盘），或导致写入缓存未能及时落盘而搞崩 ZFS 存储池元数据。

配置一台支持 **USB 信号通讯的 UPS（不间断电源）**，配合 **开源 NUT（Network UPS Tools）**，能在断电时自动广播指令，组织全屋设备安全卸载存储并平稳关机！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **选型黄金准则**：普通家庭设备推荐 **在线互动式 (Line-Interactive)**，转换时间 2~6ms，具备稳压功能；**必须选择带 USB/RJ45 通讯接口的型号**（如 APC BK650M2-CH / 山特 TG-BOX）。
> - **容量估算公式**：总设备额定功率（W）除以功率因数（通常 0.6），再预留 30% 冗余。例如全屋主机峰值 200W，建议选购 `200 / 0.6 * 1.3 ≈ 433VA` 以上规格（推荐 650VA~1000VA）。
> - **NUT 多机联动架构**：一台主机（Master/Server）直连 UPS USB 数据线，其余软路由、NAS、工作站作为 Slave/Client 监听 Master 广播，断电 5 分钟内按序自毁式优雅安全关机。

## 📊 家用 UPS 三大主流架构横向评测

| 架构类型                          | 逆变切换时间                        | 电压稳定性               | 成本与噪音            | 适用场景                            |
| :-------------------------------- | :---------------------------------- | :----------------------- | :-------------------- | :---------------------------------- |
| **后备式 (Off-Line)**             | 8~10ms (有微小跌落风险)             | 仅在停电时介入           | 极低 / 静音           | 路由器、光猫等普通小功率设备        |
| **在线互动式 (Line-Interactive)** | 🏆 **2~6ms (电脑电源完全平滑过渡)** | 🏆 **自带 AVR 自动稳压** | 🏆 **适中 / 静音**    | 🏆 **家用 NAS、PVE 小主机最佳主力** |
| **在线双变换式 (On-Line)**        | 🏆 **0ms (绝无断电时间)**           | 极致纯净正弦波           | 高昂 / 风扇常转噪音大 | 企业级机房核心机柜                  |

## 🛠️ 2026 生产级 NUT (Network UPS Tools) 局域网联动配置

```mermaid
graph TD
    UPS[UPS 不间断电源 (APC/山特)] == USB 通讯线 ==> Master[主控节点: PVE / TrueNAS (NUT Server)]
    Master -. 内网广播通知 .-> Slave1[从属节点 1: OpenWrt 软路由 (NUT Client)]
    Master -. 内网广播通知 .-> Slave2[从属节点 2: 群晖 NAS (NUT Client)]
    Master -. 内网广播通知 .-> Slave3[从属节点 3: 办公台式机 (NUT Client)]
```

### 第一步：在主服务器（Debian / PVE）安装配置 NUT Server

```bash
sudo apt update && sudo apt install nut -y
```

编辑 `/etc/nut/nut.conf` 声明模式：

```ini
MODE=netserver
```

编辑 `/etc/nut/ups.conf` 定义 USB 硬件驱动：

```ini
[myups]
    driver = usbhid-ups
    port = auto
    desc = "APC Back-UPS 650"
```

编辑 `/etc/nut/upsd.users` 创建供从机监听的安全认证账户：

```ini
[slaveuser]
    password = slave_secret_password
    upsmon slave
```

启动并验证服务：`upsc myups@localhost`，终端应即时输出电池电量（`battery.charge: 100`）与负载状态！

### 第二步：从属节点（群晖 / OpenWrt / Linux）配置客户端监听

在从机上的 `/etc/nut/upsmon.conf` 中加入：

```ini
MONITOR myups@192.168.1.100 1 slaveuser slave_secret_password slave
```

当市电中断、UPS 电池剩余 20% 时，所有从机将自动收到关机信号，同步执行 `sync && poweroff`，彻底告别拍盘与数据损毁风险！

**答**：铅酸蓄电池寿命通常为 2~3 年；建议每半年进行一次断电放电自检，若断电后支撑不到 3 分钟即跳闸，必须及时在官方或电商渠道购买同规格电池更换。
