## 🧭 一、先搞懂：Sing-box、客户端、订阅是什么关系？

新手最大的困惑就是名词太多。一句话讲清：

| 名词 | 比喻 | 你需要做什么 |
| :--- | :--- | :--- |
| **Sing-box（内核）** | 汽车发动机 | 不用管，客户端自带 |
| **客户端（GUI）** | 汽车外壳+方向盘 | 选一款装好，如 Mihomo Party |
| **订阅链接** | 加油卡 | 从机场/自建节点获取，粘贴导入 |
| **TUN 模式** | 自动挡 | 打开后全系统流量自动走代理 |
| **规则集（.srs）** | 导航地图 | 客户端自动更新，决定国内外分流 |

**结论：小白入门 = 选客户端 + 粘贴订阅 + 打开 TUN，三步走完。** 手搓 JSON 是极客进阶玩法，不是入门门槛。

## 🚀 二、为什么 2026 年大家都在转向 Sing-box？

Sing-box 被社区称为"下一代通用代理平台"，它不仅有着难以置信的跨平台一致性，还在资源占用方面做到了极致。作为"瑞士军刀"级别的全家桶内核，它的主要优势包括：

1. **极致轻量与高吞吐**：基于 Go 语言极致优化，常驻内存占用低至 15~30MB，能够轻松跑满千兆乃至万兆宽带。
2. **前沿协议原生支持**：原生支持 VLESS-Reality、Trojan、Hysteria 2、TUIC V5 等顶级抗封锁协议，无需额外安装复杂的插件。
3. **高性能 Rule Set 分流**：弃用旧版臃肿的 `.dat` 文本库，全面采用毫秒级启动的 `.srs` 二进制规则集，实现国内外流量无缝切替、防止 DNS 泄漏与广告过滤。

## 🪤 二之一、新手最常见的 5 大误区

1. **"Sing-box 就是个 App"** —— 错。它是内核，你每天打开的是客户端。内核崩了重装客户端没用，得看日志。
2. **"节点越多越好"** —— 错。100 个慢节点不如 3 个 CN2 GIA 精品节点，测速分组比堆数量重要。
3. **"全局模式最省心"** —— 错。全局模式下国内 App（微信/支付宝）可能触发风控，规则模式+分应用代理才是正解。
4. **"TUN 打开就万事大吉"** —— 错。TUN 和 DNS 泄露是两回事，开了 TUN 也要去 dnsleaktest 验证。
5. **"免费订阅真香"** —— 免费节点 IP 被万人骑，流媒体解锁基本全灭，还可能记录你的流量。入门体验可以，正经用还是付费。

## 💻 四、2026 各平台客户端选型指南

Sing-box 本身是底层内核程序，日常使用的是社区开发的图形化（GUI）客户端：

### 1. Windows 平台

- **Sing-box GUI / Desktop（官方推荐）**：界面干净优雅，支持 TUN 模式一键接管系统流量。详见 [《Windows / Mac 平台如何优雅地使用 Sing-box 客户端？》](/posts/sing-box-desktop-clients/)。
- **Mihomo Party**：2026 年大火的全新桌面客户端，颜值极高，支持一键切换内置 Sing-box 与 Mihomo 内核。深度横评可参考 [《2026 桌面端代理选型终极指南》](/posts/sing-box-vs-clash-meta/)。

### 2. macOS 平台

- **Sing-box for Mac (SFM)**：完美适配 macOS 设计规范，支持深色模式与菜单栏快速切替，TUN 模式权限管理极佳。

### 3. iOS / iPadOS 与 Apple TV (tvOS)

- **Sing-box for iOS (SFI)**：官方客户端，需要非中国区 App Store 账号免费获取，支持 iCloud 多端同步。
- **Apple TV 大屏分流**：tvOS 17/18 原生支持 SFI，免除软路由烦恼，详见 [《2026 最新 Apple TV 原生 Sing-box (SFI) 保姆级配置与流媒体分流实战》](/posts/apple-tv-singbox-tvos-setup-guide/)。
- **Shadowrocket (小火箭) / Stash / Loon / Surge**：各大主流客户端横评选购与导入教程请参考 [《iOS 代理神器大比拼》](/posts/singbox-ios-clients-comparison-shadowrocket-loon-surge-stash/)。

### 4. Android（安卓）

- **Sing-box for Android (SFA)**：官方客户端，完美支持 Android 系统级"分应用代理（Per-App Proxy）"，可单独放行微信、支付宝等国内应用，详见 [《iOS / Android 移动端 Sing-box 配置与分应用代理保姆级教程》](/posts/sing-box-mobile-clients/)。
- **Hiddify Next**：跨平台全能神器，界面极其傻瓜化，适合纯小白一键导入体验，详见 [《2026 跨平台客户端 Hiddify Next 极简新手订阅与分流配置实操》](/posts/hiddify-next-singbox-client-guide/)。

### 5. Linux / 软路由（进阶）

- 桌面 Linux 可直接运行 Sing-box CLI 或第三方 GUI；OpenWrt 软路由原生部署见 [《OpenWrt 原生部署 Sing-box (Tproxy) 透明代理保姆级教程》](/posts/openwrt-singbox-tproxy/)。

## ⚡ 五、导入订阅：极简四步实操

1. **启动客户端**：打开你的 Sing-box 界面（如 Sing-box GUI 或 Hiddify）。
2. **新建配置**：点击 **"New Profile"（新建配置）**。
3. **填入远程订阅 URL**：选择 **Remote（远程）** 模式，粘贴服务商给出的 Sing-box 链接。
4. **开启 TUN 模式并启动**：勾选 **TUN 模式（虚拟网卡）** 并点击连接，Sing-box 会接管全局流量！

---

## ✅ 六、连上之后必做的 5 件事

别以为连上就完事了，这 5 项检查决定你的体验上限：

1. **测速选节点**：用客户端的 URLTest / 自动测速选出延迟最低的节点，不要一直用默认的。
2. **确认 TUN 生效**：访问 `ip.sb` 或 `whoer.net`，确认 IP 已变为节点所在地区。
3. **检查 DNS 泄露**：去 `dnsleaktest.com` 跑 Extended Test，结果里不能出现国内运营商 IP。详细配置见 [《Sing-box 终极 DNS 配置方案》](/posts/sing-box-dns-leak-fakeip/)。
4. **分应用代理（手机）**：微信、支付宝、银行 App 设为直连，避免风控。教程见 [《移动端分应用代理保姆级教程》](/posts/sing-box-mobile-clients/)。
5. **更新规则集**：确认 `.srs` 规则集是最新版，避免用过期规则裸奔。

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 如果我的机场只提供 Clash 订阅，能直接在 Sing-box 中使用吗？

**答**：可以使用 Mihomo Party 或 Hiddify 等支持自动转换的客户端直接导入；也可以用转换工具把 YAML 转成 JSON，见 [《3 种转换方法》](/posts/convert-clash-to-singbox/)。

### Q2: 开启 TUN 模式后，游戏或 Steam 连接失败怎么办？

**答**：请确保路由规则中将本地局域网段（`192.168.0.0/16`）及 UDP 53 设为 `direct` 放行；WSL2 / Docker 冲突排查见 [《Sing-box TUN 模式终极调优》](/posts/singbox-tun-mode-wsl2-docker-optimization/)。

### Q3: Sing-box 和 Clash 我到底该用哪个？

**答**：2026 年新手无脑选 Sing-box 生态（更轻、更快、协议更新）；Clash 老用户且重度依赖 YAML 手搓，可以留守 Mihomo。深度对比见 [《选型终极指南》](/posts/sing-box-vs-clash-meta/)。

### Q4: 免费节点能用吗？

**答**：能连，但免费节点的速度、安全和稳定性都没有保障，且常被多人共用导致 IP 被流媒体拉黑。长期使用建议机场订阅或自建。

### Q5: iOS 上为什么搜不到 Sing-box？

**答**：国区 App Store 下架了此类应用，需要注册非国区 Apple ID 下载 SFI，或直接用 Shadowrocket（同样需外区账号）。

### Q6: 电脑和手机可以共用一个订阅吗？

**答**：可以。绝大多数机场订阅不限设备数（或限制 3-5 台），同一个链接粘贴到手机和电脑客户端都能用。但注意同时在线设备数别超套餐限制。

### Q7: Sing-box 需要一直开着吗？不科学上网时怎么办？

**答**：不需要。日常把客户端设为"规则模式"而非"全局模式"，国内流量自动直连，几乎零感知；只有访问外网时流量才走代理。想彻底关闭，直接退出客户端即可。

| 分流 / 规则 | 决定"哪些走代理、哪些直连"的一套规则 |
| 规则集（.srs） | 二进制规则文件，Sing-box 的分流依据，启动极快 |

| 被墙 | IP/域名被防火墙封锁，连不上 |
| 回程 / 去程 | 数据从你到服务器（去程）、从服务器回来（回程）的线路质量 |
