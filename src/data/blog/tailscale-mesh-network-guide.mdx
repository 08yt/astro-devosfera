很多朋友使用 Cloudflare Tunnel 解决了无公网 IP 下的 Web 端口映射问题，但由于流量必须经过海外边缘节点清洗，不仅**跨国延迟较高**，且无法顺畅承载 Windows 原生 RDP 远程桌面、SMB 4K 局域网原画串流或 SSH 直连。

**Tailscale** 基于极速的 WireGuard 协议内核构建，结合先进的 STUN/P2P 打洞算法，将散落在全球各地的云端 VPS、办公室电脑、手机与家庭 NAS 编织成一个安全平坦的 `100.x.x.x` 虚拟私网！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **底层协议**：采用 Linux 内核级 WireGuard 协议加密，性能损耗极低，支持全平台（Windows / macOS / iOS / Android / Linux）。
> - **P2P 直连与打洞**：90%+ 的复杂网络环境下实现设备两两之间直连（UDP Hole Punching），不经过任何第三方服务器中转。
> - **子网路由 (Subnet Router)**：软路由节点单条命令开启子网广播，全网设备无需安装客户端即可畅访整个家庭局域网。
> - **自建 DERP 保障**：在低延迟海外 VPS 上自建私有 DERP 中继，打破极端对称 NAT 下的中继卡顿。

## 🛠️ 2026 生产级三大核心玩法配置

### 1. 声明子网路由 (Subnet Router)

在内网软路由或常开的 Linux/NAS 上运行：

```bash
# 开启 Linux 内核 IPv4/IPv6 转发
echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.conf
sudo sysctl -p /etc/sysctl.d/99-tailscale.conf

# 宣告家庭局域网网段 (例如 192.168.1.0/24)
tailscale up --advertise-routes=192.168.1.0/24 --accept-routes
```

> **管理审批**：在 Tailscale 网页控制台（Machines）找到该设备，在 **Edit route settings** 中勾选通过宣告的子网即可！

### 2. 声明安全出口网关 (Exit Node)

如果你拥有一台高带宽海外 VPS（如搬瓦工或 DMIT），只需执行：

```bash
tailscale up --advertise-exit-node
```

在移动端客户端勾选 **Use exit node**，全设备的所有公网流量瞬间经由该 VPS 安全加密出境！

## 🚀 自建私有 DERP 中继服务器（彻底告别官方海外中继）

当家庭宽带与移动网络都是严苛的“对称型 NAT”时，P2P 打洞失败会自动转走官方 DERP 节点（位于海外，延迟高达 200ms+）。

在自建海外/国内 VPS 上部署 Docker 版 `derper`：

```yaml
services:
  derper:
    image: fredliang/derper
    container_name: tailscale_derp
    restart: unless-stopped
    ports:
      - "443:443"
      - "3478:3478/udp" # STUN 穿透端口
    environment:
      - DERP_DOMAIN=derp.yourdomain.com
      - DERP_CERT_MODE=manual
      - DERP_ADDR=:443
      - DERP_STUN=true
      - DERP_VERIFY_CLIENTS=true
    volumes:
      - ./certs:/app/certs
      - /var/run/tailscale/tailscaled.sock:/var/run/tailscale/tailscaled.sock
```

在 Tailscale Admin Console 的 **Access Controls (ACL)** 中将自建节点加入 `derpMap`，打洞中继延迟瞬间骤降至 30ms 级别！

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: Tailscale 会泄漏家庭网络真实 IP 吗？

**答**：不会。所有通信数据均通过 WireGuard 端到端公私钥签名加密，Tailscale 控制平面仅负责密钥交换与连接调度，无法解密或窥探传输内容。

### Q2: 搭建私有 DERP 节点的海外 VPS 选哪家网络更好？

**答**：在 **DMIT** 或 **搬瓦工** 的 **中国电信 CN2 GIA** 或 **联通 AS9929** 专线 VPS 上自建 DERP，跨国端对端 RDP 远程桌面能达到 60 FPS 丝滑无撕裂。选购参考见 [《2026 国外 VPS 选购指南》](/posts/vps-buying-guide-2026/)。
