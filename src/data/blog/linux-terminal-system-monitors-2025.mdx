## 1. 颜值与极速的双料巅峰：Bottom (btm)

如果只能推荐一款工具来取代 `htop`，那绝对是 **Bottom**（命令为 `btm`）。

这是一款使用 Rust 纯手工打造的跨平台图形监控器。当你第一次在终端里敲下 `btm` 时，你会惊叹于原本冰冷的终端竟然可以渲染出如此细腻丝滑的动态实时折线图！

### 安装

```bash
# 使用 Cargo（跨平台推荐）
cargo install bottom --locked

# macOS 使用 Homebrew
brew install bottom

# Debian / Ubuntu
curl -LO https://github.com/ClementTsang/bottom/releases/latest/download/bottom_amd64.deb
sudo dpkg -i bottom_amd64.deb
```

### 核心亮点

- **极其直观的折线图**：把 CPU 的每个核心、内存随时间的变化历史、整台机器的网络流量吞吐量，全部画成动态的折线图谱。你一眼就能看出过去一分钟内服务器经历了什么流量尖峰；
- **极低的性能开销**：Rust 的内存安全和极高的执行效率使得渲染如此酷炫的图形，CPU 占用率依旧微乎其微（< 0.5%）；
- **Vim 快捷键绑定**：完全支持 `h, j, k, l` 在不同的监控面板之间穿梭，双手不离键盘就能过滤并杀掉卡死的进程；
- **进程树视图**：按 `T` 键切换为树状视图，清楚看出哪个父进程在吃资源。

## 2. 大包大揽的全能王：Glances

如果你觉得 `btm` 依然只局限在 CPU 和内存层面，那么 Python 编写的 **Glances** 就是那个"什么都要监控"的控制狂。

### 安装

```bash
# 通过 pip 安装（推荐 pipx 隔离环境）
pipx install glances

# 或者 Docker 部署（推荐用于服务器远程监控）
docker run -d \
  --name glances \
  --pid=host \
  --network=host \
  --privileged \
  -e GLANCES_OPT="-w" \
  -v /var/run/docker.sock:/var/run/docker.sock:ro \
  --restart unless-stopped \
  nicolargo/glances:latest-full
```

### 核心亮点

它在一个屏幕里塞下了难以置信的信息量：

- **温度传感器**：直接读取服务器主板和 CPU 的物理温度传感器，显示当前转速和摄氏度；
- **Docker 容器感知**：单独列出每个正在运行的容器实际消耗的内存和 CPU；
- **Web Server 模式**：执行 `glances -w`，直接在浏览器输入 `http://IP:61208` 访问带颜色的实时监控面板，**无需 VPN 即可远程运维**；
- **API 模式**：`glances --export-restful`，可将数据推送给 Prometheus / InfluxDB + Grafana。

## 3. 赛博朋克旗舰：Btop++ (btop)

Btop++ 是最初 Bpytop / Bashtop 系列工具的 **C++ 高性能重写版**，在 GitHub 上拥有超过 22k ⭐。

### 安装

```bash
# macOS / Linux（Homebrew）
brew install btop

# Arch Linux
sudo pacman -S btop

# 手动编译（针对 ARM 服务器）
git clone https://github.com/aristocratos/btop.git
cd btop && make && sudo make install
```

### 核心亮点

- **赛博朋克 UI**：带圆角精致边框、渐变色条，是 README 里最适合截图晒图的工具；
- **详细进程树**：树状结构展示进程父子关系，便于定位进程组的资源消耗源头；
- **GPU 监控**（v1.3+）：支持 NVIDIA / AMD GPU 利用率和显存占用，适合 AI/深度学习 Homelab；
- **完全键盘驱动**：支持鼠标交互同时兼容纯键盘操作，SSH 远程场景下也不受限。

## 4. 系统信息快照：Fastfetch（取代 Neofetch）

Fastfetch 严格来说不是监控工具，但它是**炫耀你的 Homelab 配置**的必备利器，用 C 语言重写，速度比 Python 版的 Neofetch 快 10 倍以上。

```bash
# 安装
brew install fastfetch   # macOS / Linux

# 运行
fastfetch
```

输出包括发行版、内核、CPU/GPU 型号、内存、磁盘使用率和 ASCII 艺术 Logo，一条命令搞定系统快照。

## ❓ 常见问题与 AI 快问快答 (FAQ)

**Q：`btm` 和 `btop` 我该选哪个？**

A：**日常运维首选 `btop++`**，功能最全（GPU 支持、鼠标交互），UI 最漂亮；**如果你在乎极致低内存占用或跑在资源紧张的 ARM 设备上，选 `btm`**，Rust 二进制体积更小，开销更低。

**Q：Glances 的 Web 模式安全吗？直接暴露在公网？**

A：默认监听所有接口 `0.0.0.0:61208`，**不要直接暴露在公网**。推荐通过 Nginx 反向代理添加 Basic Auth，或者通过 SSH 端口转发访问：`ssh -L 61208:localhost:61208 user@server`，然后本地浏览器打开 `http://localhost:61208`。

**Q：在 Docker 容器里能用这些工具吗？**

A：可以，但需要特殊权限。运行 Glances 时加 `--pid=host --privileged` 才能看到宿主机全部进程；btop / btm 运行在容器内只能看到容器内的进程，加 `--pid=host` 同样可以访问宿主机进程。

**Q：如何在 Homelab NAS（群晖）上安装 btm？**

A：群晖 DSM 7.x 基于 Linux，可以在 SynoCommunity 安装 `Entware`，然后通过 `opkg install bottom`；或者下载对应 CPU 架构（x86_64 / aarch64）的预编译二进制直接运行。

**Q：这些工具能集成到 Grafana 监控大盘吗？**

A：Glances 直接支持 `--export-influxdb` 推送到 InfluxDB，再由 Grafana 读取；btm 和 btop 本身没有 export 功能，但可以配合 **Node Exporter + Prometheus** 体系来实现更完整的长期监控和告警。
