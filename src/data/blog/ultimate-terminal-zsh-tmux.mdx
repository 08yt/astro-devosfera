无论是写代码、调试 Docker 还是运维我们的 Sing-box 节点，**Terminal（终端）** 是极客与服务器沟通的唯一桥梁。

然而，大多数 Linux 发行版默认提供的 `bash` 极其简陋：黑底白字、没有好用的自动补全、敲错一个字母就要退格按半天；更致命的是，当你跑一个长达几十分钟的脚本时，如果本地网络稍微闪断一下，SSH 一断开，脚本直接被系统杀死，前功尽弃！

今天，我们将安装 Linux 命令行"装机必备三件套"，打造一个炫酷、高效、不掉线的终端环境。

## 第一层：Zsh + Oh My Zsh 提供视觉与扩展

Zsh 是一种比 Bash 强大得多的 Shell，而 Oh My Zsh 则是它最负盛名的傻瓜式插件管理系统。

### 安装 Zsh 与 Oh My Zsh

```bash
# Debian / Ubuntu
sudo apt update && sudo apt install zsh git curl -y

# 改变默认 Shell 为 Zsh
chsh -s $(which zsh)

# 一键安装 Oh My Zsh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

### 安装两大让效率起飞的插件

Oh My Zsh 中有两个插件是神一般的存在：

```bash
# 自动补全插件：根据历史命令用灰色提示，→ 键确认补全
git clone https://github.com/zsh-users/zsh-autosuggestions \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions

# 语法高亮插件：命令正确显示绿色，错误显示红色
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

编辑 `~/.zshrc`，找到 `plugins=(git)` 一行，改为：

```bash
plugins=(git zsh-autosuggestions zsh-syntax-highlighting z docker)
```

然后执行 `source ~/.zshrc` 生效。

### Starship：Rust 编写的极速提示符

配合 [Starship](https://starship.rs) 替换 Oh My Zsh 默认主题，获得毫秒级启动速度和极高颜值：

```bash
curl -sS https://starship.rs/install.sh | sh
# 在 ~/.zshrc 底部添加
echo 'eval "$(starship init zsh)"' >> ~/.zshrc
```

## 第二层：Tmux — 永不断线的"后端窗口"

Tmux 是所有玩云服务器的人必须最先学会的软件。它是一个**终端复用器（Terminal Multiplexer）**，核心作用是：**将终端会话和 SSH 连接完全分离。**

### 安装

```bash
sudo apt install tmux -y
```

### 核心使用场景

当你需要编译一个几小时的内核，或者运行长时间的 Docker pull：

```bash
# 1. 创建一个命名会话（推荐命名，方便管理）
tmux new -s build

# 2. 运行你的长耗时命令
pnpm run build

# 3. 按下 Ctrl+B，然后按 d（detach）
# 你"脱离"了这个窗口，它在服务器后台继续全速跑着

# 4. 哪怕你拔掉网线、把电脑关机，服务器上的进程绝不会中断！
# 5. 明天换一台电脑 SSH 连上，执行：
tmux attach -t build
# 昨晚那个满屏幕跑代码的界面原封不动地回到你的眼前！
```

### 常用快捷键速查

所有 Tmux 快捷键均以 **`Ctrl+B`** 为前缀（先按 Ctrl+B，松开后再按目标键）：

| 快捷键          | 作用                      |
| --------------- | ------------------------- |
| `Ctrl+B d`      | Detach 脱离当前会话       |
| `Ctrl+B c`      | 在当前会话中创建新窗口    |
| `Ctrl+B n / p`  | 切换到下一个 / 上一个窗口 |
| `Ctrl+B %`      | 垂直分割当前面板          |
| `Ctrl+B "`      | 水平分割当前面板          |
| `Ctrl+B 方向键` | 在分割面板之间移动焦点    |
| `Ctrl+B [`      | 进入滚动模式（`q` 退出）  |

### 推荐的 `~/.tmux.conf` 基础配置

```bash
# 将前缀改为 Ctrl+A（更符合老 Screen 用户习惯）
# unbind C-b
# set-option -g prefix C-a

# 开启鼠标支持（可以鼠标点击切换面板）
set -g mouse on

# 窗口和面板编号从 1 开始（更直观）
set -g base-index 1
setw -g pane-base-index 1

# 状态栏美化（底部显示会话名、窗口列表）
set -g status-style bg=colour235,fg=colour136
set -g status-left '#[bold]#S '
set -g status-right '%Y-%m-%d %H:%M'

# 历史滚动行数增加
set -g history-limit 10000
```

## 第三层：Zoxide — 目录跳转的读心术

你一定早就厌倦了繁琐的 `cd /var/log/sing-box` 这种漫长的路径切换命令。**Zoxide** 是采用 Rust 编写的极速智能目录跳转工具，会学习你最常访问的目录并建立频率模型。

### 安装

```bash
# 方式一：官方脚本（推荐）
curl -sS https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh | bash

# 方式二：通过包管理器
sudo apt install zoxide  # Debian 12+ / Ubuntu 24.04+
brew install zoxide      # macOS
```

在 `~/.zshrc` 底部添加：

```bash
eval "$(zoxide init zsh)"
```

### 使用示例

```bash
# 第一次手动访问目录（zoxide 开始学习）
cd /root/singbox
cd /var/www/myblog
cd /opt/docker/stacks

# 之后只需输入关键词首字母，zoxide 自动跳转最高频目录
z si      # → /root/singbox
z blog    # → /var/www/myblog
z sta     # → /opt/docker/stacks
z si bl   # 多关键词精确匹配
```

## 一键配置脚本（新 VPS 开箱即用）

将以下脚本保存为 `setup-terminal.sh`，在新 VPS 上一键完成全套配置：

```bash
#!/bin/bash
set -e

echo "=== 1. 安装依赖 ==="
sudo apt update && sudo apt install -y zsh git curl tmux

echo "=== 2. 安装 Oh My Zsh ==="
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)" "" --unattended

echo "=== 3. 安装 Zsh 插件 ==="
git clone --depth=1 https://github.com/zsh-users/zsh-autosuggestions \
  "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-autosuggestions"
git clone --depth=1 https://github.com/zsh-users/zsh-syntax-highlighting \
  "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting"

echo "=== 4. 安装 Starship 提示符 ==="
curl -sS https://starship.rs/install.sh | sh -s -- --yes

echo "=== 5. 安装 Zoxide ==="
curl -sS https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh | bash

echo "=== 6. 写入 .zshrc 配置 ==="
cat >> ~/.zshrc << 'EOF'
plugins=(git zsh-autosuggestions zsh-syntax-highlighting z docker)
eval "$(starship init zsh)"
eval "$(zoxide init zsh)"
alias ls='eza --icons'
alias ll='eza -la --icons --git'
EOF

echo "=== 7. 设置默认 Shell 为 Zsh ==="
chsh -s "$(which zsh)"

echo "✅ 全套终端配置完成！重新登录 SSH 后生效。"
```

## ❓ 常见问题与 AI 快问快答 (FAQ)

**Q：Tmux 和直接用 `nohup` 或 `&` 后台运行有什么区别？**

A：`nohup` 和 `&` 只是让进程在后台运行，但你**无法重新连接并查看实时输出**。Tmux 保留了完整的终端会话，包括交互式输出、历史滚动和多窗格布局，随时可以重新 attach 查看实时状态，是更适合长期运维的方案。

**Q：Oh My Zsh 让我的终端启动变慢了，怎么办？**

A：Oh My Zsh 加载了大量插件时确实会拖慢启动。解决方案：① 精简 `plugins` 列表，只保留实际用到的插件；② 改用更轻量的框架 [Zinit](https://github.com/zdharma-continuum/zinit)（延迟加载插件）或 [Sheldon](https://sheldon.cli.rs)；③ 改用完全基于 Rust 的 [Warp Terminal](https://www.warp.dev)（内置现代化 Shell 体验）。

**Q：Zoxide 的 `z` 命令和 Oh My Zsh 自带的 `z` 插件冲突怎么办？**

A：两者都有 `z` 命令。推荐**禁用 Oh My Zsh 的 `z` 插件**（从 `plugins` 列表中移除），完全使用 Zoxide——它的频率算法更先进，速度也更快（Rust vs Shell script）。

**Q：在 macOS 上这套方案同样适用吗？**

A：完全适用。macOS 自 Catalina 起默认 Shell 已改为 Zsh，只需跳过 `chsh` 步骤。Tmux 通过 `brew install tmux` 安装，Zoxide 通过 `brew install zoxide` 安装，体验与 Linux 完全一致。

**Q：如何让 Tmux 在服务器重启后自动恢复会话？**

A：使用 [tmux-resurrect](https://github.com/tmux-plugins/tmux-resurrect) 插件保存/恢复会话，配合 [tmux-continuum](https://github.com/tmux-plugins/tmux-continuum) 可以实现每 15 分钟自动保存，服务器重启后开机自动恢复所有窗口和面板布局。
