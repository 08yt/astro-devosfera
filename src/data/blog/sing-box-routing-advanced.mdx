经过基础入门，你已经在 `outbounds` 里面配置好了多个代理节点。但在日常使用中，如果你让*所有的*流量都走代理，不仅会耗费机场流量，访问国内京东、淘宝时也会极其卡顿。

这个时候，就需要进入 Sing-box 的 `route` (路由分流) 核心操作室了！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **分流原理**：Sing-box 根据域名、IP、进程名等规则，将流量分发给指定的 `outbound`（如 `direct` 直连、`proxy` 代理或 `block` 屏蔽）。
> - **2026 规则规范**：不再推荐旧版 `.dat` 依赖，全面采用二进制 `.srs` 规则集 (`rule_set: ["geosite-cn"]`) 实现毫秒级超轻量匹配。
> - **规则优先级**：`rules` 数组内自上而下匹配，匹配即止。最上方的规则优先级最高。
> - **国际版阅读**：本指南同时发表于 Medium 平台：[Sing-box Routing Advanced Guide on Medium](https://medium.com/@mjiaguo/sing-box-routing-advanced-50fac34d9a7c)。

## 🛠️ 1. 2026 标准国内外分流配置 (基于 Rule Set)

在配置文件的 `route` 模块配置二进制 `.srs` 规则集：

```json
{
  "route": {
    "rule_set": [
      {
        "tag": "geosite-cn",
        "type": "remote",
        "format": "binary",
        "url": "https://raw.githubusercontent.com/SagerNet/sing-geosite/rule-set/geosite-cn.srs",
        "download_detour": "proxy"
      },
      {
        "tag": "geoip-cn",
        "type": "remote",
        "format": "binary",
        "url": "https://raw.githubusercontent.com/SagerNet/sing-geoip/rule-set/geoip-cn.srs",
        "download_detour": "proxy"
      }
    ],
    "rules": [
      {
        "rule_set": ["geosite-cn", "geoip-cn"],
        "outbound": "direct"
      }
    ],
    "final": "proxy"
  }
}
```

## 🛠️ 2. 屏蔽广告与黑名单域名

创建一个 `block` 出站，并在 `rules` 顶部优先进行拦截：

```json
{
  "outbounds": [
    { "type": "selector", "tag": "proxy", "outbounds": ["node-us", "node-hk"] },
    { "type": "direct", "tag": "direct" },
    { "type": "block", "tag": "block" }
  ],
  "route": {
    "rules": [
      {
        "domain_suffix": ["baidu-ads.com", "adservice.google.com"],
        "outbound": "block"
      },
      {
        "rule_set": ["geosite-cn", "geoip-cn"],
        "outbound": "direct"
      }
    ],
    "final": "proxy"
  }
}
```

## 🛠️ 3. ChatGPT / Netflix 专属节点分流

为受限的 AI 与流媒体应用分派特定解锁出站：

```json
{
  "route": {
    "rules": [
      {
        "domain_suffix": ["chatgpt.com", "oaistatic.com"],
        "outbound": "node-us"
      },
      {
        "domain_suffix": ["netflix.com"],
        "outbound": "node-hk"
      }
    ]
  }
}
```

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 匹配规则中 `domain` 与 `domain_suffix` 有什么区别？

**答**：`domain` 要求域名完全精确匹配（如 `"google.com"`）；而 `domain_suffix` 会包含子域名匹配（如 `".google.com"` 包含 `mail.google.com` 和 `maps.google.com`）。

### Q2: 自建 Sing-box 节点搭配哪种线路分流体验最好？

**答**：国外代理出站建议搭配 **中国电信 CN2 GIA** 或 **联通 AS9929** 高速线路 VPS；流媒体分流建议搭配拥有原生家宽 IP 的香港/日本机房。
