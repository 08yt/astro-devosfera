随着海外 VPS 节点与家庭 Homelab 服务的增多，突然无法上网或服务异常时，往往需要逐一 SSH 登录排查。

相比 Zabbix 或 Prometheus + Grafana 等重量级企业监控，个人站长与极客需要的是一款开箱即用、颜值炸裂、报警灵敏的轻量级探针。

**Uptime Kuma** 凭借极具设计感的“绿色心跳药丸墙”、覆盖 90+ 渠道的即时通知告警与几乎为零的系统资源占用，成为了现代自托管服务监控的绝对标配！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **全协议高并发探测**：支持 HTTP(s)、TCP Port（监测 Sing-box/SSH 端口）、Ping (ICMP)、DNS、Docker Container 内部健康状态与 Push 探针。
> - **SSL 证书到期预警**：自动监控域名 SSL 证书剩余有效天数，在到期前 7 天/14 天触发推送提醒，彻底告别证书过期翻车。
> - **秒级全渠道通知**：服务异常或恢复时，毫秒级推送至 Telegram Bot、Discord、Bark、飞书、企业微信与钉钉。
> - **公开状态页 (Status Page)**：一键生成对访客可见的高级状态看板，并支持嵌入自定义徽章（Shields Badges）。

## 🛠️ 2026 生产级 Docker Compose 部署

在最稳定的核心 VPS（如搬瓦工或 DMIT 节点）上创建 `compose.yaml`：

```yaml
services:
  uptime-kuma:
    image: louislam/uptime-kuma:1
    container_name: uptime_kuma
    restart: unless-stopped
    ports:
      - "3001:3001"
    volumes:
      - ./data:/app/data
```

启动服务：`docker compose up -d`。

## 🚀 监控项添加最佳实践

1. **监测出海代理节点 (Sing-box / VLESS / Hysteria 2)**：
   - 监控类型：选择 **TCP 端口**（不要仅选 Ping，很多机房或网络环境对 ICMP 有针对性丢包或封锁）。
   - 主机名：输入 VPS 独立 IP；端口：输入节点监听的端口（如 `443` 或高位端口）。
   - 心跳间隔：`60` 秒；重试次数：`3` 次（防偶发抖动误报）。
2. **监测 Web 网站与证书**：
   - 监控类型：选择 **HTTP(s)**，输入 `https://yourdomain.com`。
   - 勾选 **证书到期通知**，默认提前 14 天触发告警。
3. **配置 Telegram 告警机器人**：
   - 在 **设置 -> 通知 -> 设置通知** 选择 Telegram。
   - 填入 Bot Token 与 Chat ID，点击“测试”即可验证秒级推送。
