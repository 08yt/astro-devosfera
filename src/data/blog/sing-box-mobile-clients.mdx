手机作为我们日常使用频率最高的智能设备，**Sing-box** 在移动端的表现堪称“性能与省电的双重王者”。

基于 Go 语言的并发架构使得 Sing-box 在后台常驻时电池消耗极低，且能够秒速响应无线网络（Wi-Fi / 5G）之间的网络无感切换。

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **iOS 苹果端**：推荐使用官方免费应用 **Sing-box for iOS (SFI)**（需外区 Apple ID），或第三方老牌神器 **Shadowrocket (小火箭)** / **Stash**。
> - **Android 安卓端**：推荐使用官方 **Sing-box for Android (SFA)** 或 **Hiddify Next**，利用 **Per-App Proxy (分应用代理)** 功能强行隔离国内 App。
> - **配置核心**：导入远程订阅 URL，允许安装系统 VPN 描述文件即可启动。

## 📱 一、iOS 苹果端：SFI 与小火箭 (Shadowrocket) 配置

### 1. 如何下载客户端？

由于政策原因，SFI 与 Shadowrocket 无法在大陆 App Store 上架。

- **获取方案**：登录一个非中国区（如美区、日区或港区）的 Apple ID。在商店中搜索 **Sing-box**（官方蓝色图标，由 SagerNet 免费发布）或 **Shadowrocket**。

### 2. 导入节点与启动

在 SFI 客户端中点击 **Profiles** -> **Add Remote Profile**，粘入服务商给出的远程 Sing-box 订阅链接。点击保存后允许安装 iOS 系统 **VPN 描述文件**，在首页大按钮开启连接即可。

## 🤖 二、Android 安卓端：SFA 分应用代理 (Per-App Proxy)

在安卓系统上，通过 GitHub Releases 或 Google Play 下载安装 **SFA (Sing-box for Android)** APK 文件。

SFA 的最大亮点在于系统赋予的神级功能 —— **真身·分应用代理 (Per-App Proxy)**。这是防止微信、淘宝、抖音等国内大厂 App 误走代理的最彻底手段！

### 分应用代理实操步骤：

**为什么要开启分应用代理？**
国内视频与社交应用流量巨大，若误走代理不仅白白消耗节点流量，还容易触发异地登录风控。通过白名单/黑名单模式，只让外网软件走代理：

1. 打开 SFA 进入 **Settings (设置)** 页面。
2. 找到并开启 **Per-App Proxy (应用层分流)**。
3. 选择分流模式：
   - **Bypass Mode (黑名单模式，推荐)**：勾选微信、支付宝、抖音、哔哩哔哩等国内全家桶，使其强制直连。
   - **Proxy Mode (白名单模式)**：仅勾选 X (Twitter)、YouTube、Telegram、ChatGPT 等海外应用，其余默认放行。
4. 保存配置并重新启动连接。

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 手机开着 Sing-box 节点，连接 Wi-Fi 切换到 5G 时断网怎么办？

**答**： Sing-box 原生具备自动网络重连机制。如果在切换网络时卡顿，可在设置中开启 `Auto Reconnect`（自动重连）与 `Strict Route`（严格路由防护）。

### Q2: 为什么在 iOS 上使用小火箭导入 Sing-box 节点显示“不支持的协议”？

**答**：请确保已将小火箭升级到 2026 最新版本。最新版小火箭、Stash 与 Loon 均已完整内建了 Sing-box 的 VLESS-Reality 与 Hysteria 2 协议解析内核。
