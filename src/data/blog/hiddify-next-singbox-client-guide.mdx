## 📝 三、第二步：极简订阅配置实操

配置 Hiddify Next 仅需两步，小白玩家也能在 1 分钟内搞定：

### 1. 导入订阅配置文件

1.  启动 Hiddify Next，首次进入会提示选择语言，选择“**简体中文**”。
2.  在主界面，点击中间最显眼的 **“+ 添加配置”** 按钮。
3.  选择 **“添加新订阅（从剪贴板）”** （在此之前，请先复制好你的机场订阅链接）或者选择“扫描二维码”直接扫描。
4.  软件会自动连接云端拉取节点，拉取成功后，主界面会显示你的订阅包卡片。

### 2. 启动代理与模式切换

1.  回到主界面，点击正中心大圆圈的 **“开始/连接”** 按钮。如果系统提示申请 VPN 或网卡写入权限，请勾选**同意并放行**。
2.  在主界面左下角，你可以非常方便地切换工作模式：
    - **规则模式（推荐）**：国内流量直连，海外网站走节点代理，自动避免微信、淘宝卡顿。
    - **全局模式**：所有流量强制走代理节点。
    - **直连模式**：完全不使用代理，直接物理连接。
3.  点击底部的 **“节点列表”** 按钮，系统会展示当前订阅下的所有可用节点，点击闪电图标可以一键测速，选择延迟最低的绿色节点即可。

## 🔧 四、进阶：启用本地 TUN 系统接管

默认情况下，Hiddify 使用系统 HTTP 代理。这只能接管浏览器等支持系统代理的流量，而终端命令行、Git clone、Spotify 或一些外服游戏依然会绕过代理。

要在 Hiddify 中开启强制接管整台电脑的 **TUN 模式**，配置十分简单：

1.  点击左侧菜单的 **“设置”**（Settings）。
2.  找到 **“VPN 模式 / 虚拟网卡”** 选项并将其勾选开启。
3.  如果是在 Windows 系统下，建议在设置中开启 **“以管理员身份运行”**，以便 Hiddify 在每次启动时自动向路由表写入最高优先级的网路 Metric 指标。
4.  开启后，所有的软件流量都将被 Sing-box 核心完美代理。
