**Sing-box** 内核因强悍的传输效率、极低的内存开销以及对 VLESS-Reality、Hysteria 2、TUIC v5 的原生支持，已成为极客圈标配。

但官方客户端手搓 JSON 的高门槛让很多新手望而却步。

**Hiddify Next**（基于 Flutter 与 Sing-box 核心构建）完美解决了这一难题 —— 既继承了 Sing-box 的极致性能，又拥有开箱即用的可视化界面与本地自动订阅转换能力！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **全格式本地自解析**：无需外部转换 API，直接将 Clash YAML、Base64 或 Sing-box 订阅粘贴进 Hiddify 即可自动识别。
> - **一键 TUN 模式**：内置系统级虚拟网卡，点击开启即可全局接管命令行、游戏与桌面应用。
> - **多端一致性**：原生覆盖 Windows、macOS、Linux、Android 与 iOS，操作逻辑与 UI 100% 保持一致。

## 🛠️ Hiddify Next 极简三步上手

### 1. 导入订阅

启动 Hiddify Next，点击 **“+ 添加配置”** -> 选择 **“从剪贴板添加”** 粘贴机场订阅 URL，软件自动在本地解析节点列表。

### 2. 模式选择与一键测速

在主界面选择 **“规则模式（Rule）”**（国内直连、海外代理），点击底部的闪电图标进行批量延迟测速，选中延迟最低的绿色节点。

### 3. 开启 TUN 虚拟网卡

在设置中开启 **“VPN 模式 / TUN”**，全系统所有应用流量即刻无感走代理。
