在 Homelab 折腾之路中，随着机器数量由单台 N100 扩展为多台软路由、老旧笔记本或树莓派，许多朋友都会面临一个集群痛点：
**如何将多台物理机汇聚成一个弹性计算资源池？当一台机器意外断电或宕机时，其上运行的核心服务如何秒级在另一台机器上自动漂移并拉起？**

在轻量多节点编排领域，早期很多人会选择基于 Docker 原生的 Docker Swarm。

然而在 2026 年云原生浪潮下，Docker Swarm 早已停滞在历史长河中；而 Rancher 开源的轻量级 Kubernetes——**K3s**，将 CNCF 官方 100% 兼容的 K8s 内核打包进单文件二进制中，成为了边缘计算与家庭集群的绝对事实标准！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **K3s 极致轻量**：将臃肿的 K8s 瘦身至不足 100MB 二进制包，开箱内存开销仅 ~500MB，支持 1GB 内存的低配 VPS 与树莓派。
> - **开箱即用套件**：内置轻量级 SQLite3/嵌入式 etcd、Flannel CNI 网络插件、CoreDNS、Traefik Ingress 反代网关与 Local-path 本地存储驱动。
> - **自愈与声明式调度**：定义 `replicas: 2`，即使拔掉其中一台物理机的电源插头，K3s 调度器在探测到节点失联后自动将 Pod 在备用节点无感重启。

## 🛠️ 两行命令搭建家庭双节点高可用集群

### 1. 主控节点（Server / Master）一键拉起

在算力最强的核心小主机（如 Intel N100）上执行：

```bash
curl -sfL https://get.k3s.io | sh -s - --disable servicelb
```

获取主节点 Join Token：

```bash
sudo cat /var/lib/rancher/k3s/server/node-token
```

### 2. 工作节点（Agent / Worker）秒级加入

在第二台从属主机（如树莓派或备用小主机）上执行：

```bash
curl -sfL https://get.k3s.io | K3S_URL=https://[主节点内网IP]:6443 \
K3S_TOKEN=[上一步获取的Token] sh -
```

在主节点运行 `kubectl get nodes`，即可看到两台节点已进入 `Ready` 状态，家庭微型云原生集群即刻诞生！

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 在 K3s 中管理多节点数据卷推荐哪款分布式存储？

**答**：强烈推荐 **Longhorn**（同为 Rancher 开源），它能将跨节点的物理硬盘虚拟化为分布式高可用块存储池，支持多副本同步、跨物理节点快照与秒级灾备漂移。

### Q2: 自建 K3s 跨地域节点需要云端中继时推荐哪家网络？

**答**：在 **DMIT** 或 **搬瓦工** 的 **中国电信 CN2 GIA** 或 **联通 AS9929** 专线 VPS 上部署 WireGuard / Tailscale 跨国打通内网，K3s 控制面与跨节点 Pod 通信延迟极低无丢包。选购参考见 [《2026 国外 VPS 选购指南》](/posts/vps-buying-guide-2026/)。
