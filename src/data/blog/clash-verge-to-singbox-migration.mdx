随着 Clash 原版核心彻底停更，虽然目前社区有 Clash Verge Rev 在苦苦支撑，但在网络底层的并发性能、内存占用以及对最前沿协议（如 Hysteria 2、TUIC v5、VLESS-Reality）的支持上，**基于 Go 原生开发、无套壳内核的 Sing-box 已经成为无可争议的下一代标配。**

今天这篇保姆级教程，将用最通俗易懂的对比方式，带你将 Clash 配置文件无损“翻译”成 Sing-box 的 JSON 规则，助你完美平滑迁移！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **策略组平替**：Clash `type: select` 对应 Sing-box `type: selector`；`type: url-test` 对应 `type: urltest`（测速间隔 `interval: "5m"`）。
> - **分流规则平替**：Clash `rules:` 数组对应 Sing-box `route.rules`，2026 标准推荐使用二进制 `.srs` 规则集 (`rule_set: ["geosite-cn"]`)。
> - **流控校验**：VLESS-Reality 在 Sing-box 中必须指定 `"flow": "xtls-r-flow"`，与 `multiplex` 互斥。

## 🗺️ 一、核心概念对比：YAML 与 JSON 的映射关系

只要搞懂概念映射，迁移就完成了一半：

| 配置功能         | Clash (YAML) 写法 | Sing-box (JSON) 平替 | 作用解释                               |
| :--------------- | :---------------- | :------------------- | :------------------------------------- |
| **独立节点**     | `proxies:`        | `outbounds:`         | 具体的节点 IP、端口、UUID 与 uTLS 指纹 |
| **手动策略组**   | `type: select`    | `type: selector`     | 手动切换节点或子策略组                 |
| **自动测速组**   | `type: url-test`  | `type: urltest`      | 自动测速并切换至最低延迟节点           |
| **路由分流规则** | `rules:`          | `route.rules:`       | 匹配域名/IP 决定走代理或直连           |
| **规则集**       | `rule-providers:` | `route.rule_set:`    | 2026 标准二进制 `.srs` 规则文件        |

## 🛠️ 二、核心模块平替配置模板

### 1. 策略组（Proxy Groups）平替

在 Clash 中的 `Proxy` 手动选择组与 `Auto` 自动测速组：

```json
// Sing-box 2026 标准 JSON 格式
{
  "outbounds": [
    {
      "type": "selector",
      "tag": "🚀 节点选择",
      "outbounds": ["⚡ 自动选择", "香港 CN2 GIA 01", "日本 AS9929 01"]
    },
    {
      "type": "urltest",
      "tag": "⚡ 自动选择",
      "outbounds": ["香港 CN2 GIA 01", "日本 AS9929 01"],
      "url": "http://cp.cloudflare.com/generate_204",
      "interval": "5m"
    }
  ]
}
```

---

### 2. 路由规则（Route Rules）平替

```json
// Sing-box 2026 标准路由分流
{
  "route": {
    "rule_set": [
      {
        "tag": "geosite-cn",
        "type": "remote",
        "format": "binary",
        "url": "https://raw.githubusercontent.com/SagerNet/sing-geosite/rule-set/geosite-cn.srs"
      }
    ],
    "rules": [
      {
        "rule_set": ["geosite-cn"],
        "outbound": "direct"
      }
    ],
    "final": "🚀 节点选择"
  }
}
```

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 迁移后发现 Telegram 或 𝕏 (Twitter) 图片加载变慢怎么排查？

**答**：检查出站节点的 `utls` 指纹配置。2026 标准建议在 Sing-box 节点出站添加 `"utls": { "enabled": true, "fingerprint": "chrome" }`，伪装成正常浏览器流量，避免被防火墙 QoS 限速。

### Q2: 自建 VPS 迁移至 Sing-box 后如何确保最佳延迟？

**答**：在 VPS 端部署 **VLESS + Reality (`xtls-r-flow`)** 或 **Hysteria 2** 协议。搭配 **中国电信 CN2 GIA** 或 **联通 AS9929** 海外直连线路，能获得低于 40ms 的极致握手体验。
