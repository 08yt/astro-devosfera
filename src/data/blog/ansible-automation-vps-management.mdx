当手中的海外 VPS 数量从孤立的一台扩展到三台、五台甚至几十台节点集群时，手动 SSH 登录逐一执行 `apt update` 或修改 Nginx/Sing-box 配置会变成枯燥且极易出错的负担。

**Ansible** 凭借优雅的“无 Agent (Agentless)”架构与声明式 YAML 剧本（Playbook），成为了基础设施即代码（IaC）的工业级利器！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **无 Agent 架构**：目标 VPS 无需安装任何守护进程，直接通过原生 SSH（Ed25519 密钥）安全连接与并发执行。
> - **幂等性 (Idempotency)**：重复执行 Playbook 多次，只在配置发生实际变更时才应用修改，天然避免环境脏乱。
> - **一键批量调度**：单行命令 `ansible-playbook -i hosts.ini deploy.yml` 即可在数秒内并发完成几十台节点的系统升级与服务编排。

## 🛠️ 2026 生产级 Ansible 快速上手

### 1. 编写资产清单 `hosts.ini`

```ini
[vps_nodes]
dmit_la      ansible_host=1.2.3.4   ansible_port=45678
bwh_tokyo    ansible_host=5.6.7.8   ansible_port=45678
racknerd_us  ansible_host=9.0.1.2   ansible_port=22

[vps_nodes:vars]
ansible_user=root
ansible_ssh_private_key_file=~/.ssh/id_ed25519
```

### 2. 编写批量更新与 Sing-box 守护剧本 `deploy_singbox.yml`

```yaml
- name: 批量初始化 VPS 节点
  hosts: vps_nodes
  tasks:
    - name: 确保系统包处于最新状态
      apt:
        update_cache: yes
        upgrade: dist

    - name: 开启 Linux 原生 BBR 加速
      sysctl:
        name: "{{ item.name }}"
        value: "{{ item.value }}"
        state: present
        reload: yes
      loop:
        - { name: "net.core.default_qdisc", value: "fq" }
        - { name: "net.ipv4.tcp_congestion_control", value: "bbr" }

    - name: 启动并设置 Sing-box 开机自启
      systemd:
        name: sing-box
        state: started
        enabled: yes
```

### 3. 一键并发执行

```bash
ansible-playbook -i hosts.ini deploy_singbox.yml
```

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: Ansible 跨国连接海外 VPS 经常超时怎么优化？

**答**：在 `ansible.cfg` 中开启 SSH ControlMaster 长连接复用：

```ini
[ssh_connection]
pipelining = True
ssh_args = -o ControlMaster=auto -o ControlPersist=60s
```

### Q2: 批量运维海外 VPS 时，如何选择稳定性最高的机房？

**答**：推荐混合部署 **DMIT** 或 **搬瓦工** 的 **中国电信 CN2 GIA** / **联通 AS9929** 专线小鸡作为核心跳板，配合性价比小鸡形成容灾矩阵。选购参考见 [《2026 国外 VPS 选购指南》](/posts/vps-buying-guide-2026/)。
