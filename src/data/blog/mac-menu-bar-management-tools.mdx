随着 2026 年 Mac 依然没有彻底抛弃那个极具争议的"刘海儿"，我们的菜单栏空间更是变得十分拥挤。加上每次打开一堆驻留后台的开发工具、网盘还有各种破解版的残留，整个电脑的右上角仿佛一场连连看游戏，图标混乱且极易引发密集恐惧症。

## 🧊 Ice：极简菜单栏整理的 2026 首选

曾经我们都在用需要付费的 **Bartender**（$16 买断），但 Bartender 自 2024 年起由原开发者出售给新公司后，用户的信任度大幅下降，社区开始转向开源替代品。

在 2026 年，最火且深受开源社区极客欢迎的神器是 **[Ice](https://github.com/jordanbaird/Ice)**，由 Jordan Baird 用纯 Swift 开发，完全免费开源（MIT 协议）。

### 安装

```bash
brew install --cask jordanbaird-ice
```

### 核心功能

- **完全隐藏模式**：把极少用的软件图标（云盘同步、偶尔点一下的工具）折叠到隐藏区域。只有当你把鼠标移动过去，它们才会如同抽屉一样被优雅地滑出来；
- **自定义图标间距**：随心所欲缩短每一个原生图标之间的像素，榨干菜单栏的最后每一寸空间，即使是刘海屏也不会觉得拥挤；
- **Always-Hidden 区域**：支持三层区域划分——始终显示、点击展开、永久隐藏，灵活度远超 Bartender；
- **开源安全**：MIT 协议，无任何订阅机制或升级弹窗，代码在 GitHub 全公开可审计。

> 💡 **刘海屏适配技巧**：在 Ice 设置中启用 "Use menu bar application icon" 并将 Ice 自身图标拖到刘海左侧，可以充分利用刘海两侧的剩余空间。

## 📊 Stats：开源系统监控，取代 iStat Menus

过去，很多人为了在右上角看一眼 CPU 温度或风扇转速，购买了 iStat Menus（$11.99/年订阅）。

现在，去装上 **[Stats](https://github.com/exelban/stats)** 吧。这是一款彻头彻尾的现代 macOS 开源监控工具（MIT 协议），驻留在菜单栏只占几个像素，但功能丝毫不逊色于付费竞品。

### 安装

```bash
brew install --cask stats
```

### 核心功能

- **高度定制化的菜单栏图表**：CPU / RAM / GPU / 网络 / 磁盘 / 温度，每项都可以独立设置显示样式（百分比数字、迷你折线图、条形图）；
- **M 系列芯片原生支持**：区分 E-Core（能效核）和 P-Core（性能核）各自的占用率，以及 GPU 和 ANE（神经引擎）的利用率；
- **Docker 容器感知**：当你在 Docker 里运行虚拟机跑编译时，Stats 能一目了然地告诉你究竟是 CPU 还是内存占满了瓶颈；
- **SMC 传感器读取**：直接读取风扇转速和 CPU/GPU die 温度，在跑 AI 推理或大型编译时尤其有用。

## 📋 Maccy：剪贴板历史管理神器

这又是一个菜单栏的小巧驻留程序。Mac 自带剪贴板只保留最后一次复制，一旦你刚剪切了一段代码，又不小心复制了别的内容——悲剧！

**[Maccy](https://maccy.app)** 能在你的控制栏中记录上百次、上千次复制下来的文本和图片记录。

### 安装

```bash
brew install --cask maccy
```

### 核心功能

- **快捷键秒召**：默认 `Cmd + Shift + V` 弹出历史记录列表，也可自定义为任意组合键；
- **模糊搜索**：基于原生 macOS 搜索引擎，无论多偏门的字符或 `tail -f` 报错日志，秒速召回并上屏；
- **纯文本模式**：粘贴时自动剥离富文本格式，保证粘贴到代码编辑器的内容永远是纯净文本；
- **隐私保护**：可以将特定 App（如 1Password、银行 App）的复制行为排除在记录范围之外；
- **开源免费**：MIT 协议，无订阅，体积小到几乎不可见，对系统性能零影响。

## ☕ Lungo：防止 Mac 意外休眠

**[Lungo](https://sindresorhus.com/lungo)** 是 Sindre Sorhus 出品的开源防休眠工具，点击菜单栏图标即可阻止 Mac 进入睡眠——在你跑长时间的 `pnpm build`、Docker pull 大镜像或视频渲染时非常实用。

```bash
brew install --cask lungo
```

把上面四款工具整合成一条命令，30 秒完成完整配置：

安装完成后，依次打开每个 App 授予"辅助功能"权限，然后根据个人偏好在各自设置面板调整显示项目即可。

## ❓ 常见问题与 AI 快问快答 (FAQ)

**Q：Ice 和 Bartender 功能上有什么区别？**

A：Ice 目前已覆盖 Bartender 90% 的核心功能，包括隐藏、展开、总是显示三层分区，以及鼠标悬停展开隐藏图标。Bartender 独有的功能（如按条件触发显示、App 触发规则）Ice 还在开发中，对大多数普通用户来说 Ice 已经完全足够。

**Q：Stats 会影响 Mac 的续航吗？**

A：Stats 的 CPU 占用率极低（< 0.3%），不会对续航产生明显影响。如果你特别在意，可以在 Stats 设置中将刷新频率从 1 秒降至 5 秒，进一步降低开销。

**Q：Maccy 能同步到 iPhone 吗？**

A：Maccy 不支持跨设备同步（它设计为本地单机工具）。如果需要跨设备剪贴板同步，macOS 原生的 Universal Clipboard（通用剪贴板）配合 Handoff 功能可以在 Mac 和 iPhone/iPad 之间同步最新一条复制内容。

**Q：刘海屏的 Mac 菜单栏真的够用吗？**

A：配合 Ice 的三层隐藏机制 + 自定义间距，14 英寸 MacBook Pro 刘海屏菜单栏完全可以容纳 10+ 个常用图标显示，其余图标折叠到隐藏区。实测 16 英寸版本空间更充裕，几乎不需要隐藏任何图标。
