在互联网世界里，明文 53 端口的 DNS 请求极其容易遭受运营商 ISP 窥探与投毒劫持。

利用极其轻量、并发匹配效率惊人的 **Sing-box** 作为 DNS 服务端，在 VPS 上搭建私有加密的 DoH (Port 443) 与 DoT (Port 853) 服务器，能为你全家设备提供防污染与广告拦截的极速解析体验！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **DoT (Port 853)**：基于纯 TLS 传输，握手开销低，完美适配 Android 系统级“私人 DNS”。
> - **DoH (Port 443)**：伪装为标准 HTTPS 流量，穿透力极强，支持 iOS 描述文件全局绑定。
> - **防放大攻击**：仅暴露 443/853 加密端口，彻底关闭明文 53 UDP 端口，避免 VPS 沦为 DDoS 放大器。
> - **2026 规则集**：采用二进制 `.srs` 格式规则 (`rule_set: ["geosite-ads"]`)，零开销秒级拦截广告域名。

## 🛠️ 服务端 Sing-box 加密 DNS 配置模板

在 VPS 上的 `/etc/sing-box/config.json` 部署服务端配置：

```json
{
  "inbounds": [
    {
      "type": "direct",
      "tag": "dot-in",
      "listen": "::",
      "listen_port": 853,
      "tls": {
        "enabled": true,
        "server_name": "dns.yourdomain.com",
        "certificate_path": "/etc/ssl/dns.crt",
        "key_path": "/etc/ssl/dns.key"
      }
    },
    {
      "type": "direct",
      "tag": "doh-in",
      "listen": "::",
      "listen_port": 443,
      "tls": {
        "enabled": true,
        "server_name": "dns.yourdomain.com",
        "certificate_path": "/etc/ssl/dns.crt",
        "key_path": "/etc/ssl/dns.key"
      }
    }
  ],
  "outbounds": [
    {
      "type": "direct",
      "tag": "direct-out"
    }
  ],
  "dns": {
    "servers": [
      {
        "tag": "cloudflare-doh",
        "type": "https",
        "server": "1.1.1.1",
        "detour": "direct-out"
      }
    ],
    "rules": [
      {
        "rule_set": ["geosite-ads"],
        "server": "block"
      }
    ]
  },
  "rule_set": [
    {
      "tag": "geosite-ads",
      "type": "remote",
      "format": "binary",
      "url": "https://raw.githubusercontent.com/lyc8503/sing-box-rules/rule-set-geosite/geosite-category-ads-all.srs",
      "download_detour": "direct-out",
      "update_interval": "1d"
    }
  ]
}
```

## 🤔 DoH / DoT / DoQ 怎么选？

| 协议 | 端口 | 特点 |
|---|---|---|
| DoT | 853 | 纯 TLS，握手开销小，Android"私人 DNS"原生支持 |
| DoH | 443 | 伪装成 HTTPS，穿透力最强，iOS 描述文件可全局绑定 |
| DoQ | 853/UDP | 基于 QUIC，理论延迟最低，客户端支持还少 |

**实战建议**：两个都开。Android 用户走 DoT，iOS/浏览器走 DoH，一套 VPS 全家通用。

## 🔐 证书：用 acme.sh 自动申请和续期

自建 DoH/DoT 必须用**公网 CA 签发的证书**，自签证书 Android 会直接拒绝。推荐 acme.sh：

```bash
acme.sh --issue -d dns.yourdomain.com --standalone
acme.sh --install-cert -d dns.yourdomain.com \
  --key-file /etc/ssl/dns.key \
  --fullchain-file /etc/ssl/dns.crt \
  --reloadcmd "docker restart sing-box"
```

证书 90 天过期，acme.sh 的 cron 会自动续期，`--reloadcmd` 让容器重载新证书。

## 🧱 防火墙：只留加密端口

```bash
ufw allow 443/tcp
ufw allow 853/tcp
ufw deny 53/udp   # 明文 DNS 必须关，否则 VPS 会被当成放大器攻击别人
```

这是安全红线：开放明文 53 的 UDP 的 VPS，会在几小时内被扫描器发现并利用做 DDoS 放大，你的服务商可能直接封机器。

## 📱 客户端接入姿势

- **Android**：设置 → 网络 → 私人 DNS → 填 `dns.yourdomain.com`（DoT）。
- **iOS**：用 [DNS Profile Creator](https://dpc.0x0d.sh) 生成 DoH 描述文件安装。
- **Sing-box 客户端**：在 `dns.servers` 里加一条 `https://dns.yourdomain.com/dns-query`，`detour` 走直连。

## 🛡️ 防滥用：要不要加访问控制？

Sing-box 的 DNS 服务端本身**没有鉴权机制**，任何人知道域名都能用。两个思路：

1. **低调**：域名不公开，只给家人用，被扫到的概率极低。
2. **白名单**：防火墙只放行你家宽带的 IP 段，最彻底但换 IP 要改规则。

别在公网论坛晒你的 DNS 域名，道理和晒节点订阅链接一样。

### Q1: 自建 DoH/DoT 服务器对 VPS 的物理延迟有要求吗？

**答**：对延迟极度敏感！域名解析发生在任何 HTTP 握手之前。建议选择 **DMIT** 或 **搬瓦工** 包含 **中国电信 CN2 GIA** 或 **联通 AS9929** 高速回程的机房，确保解析延迟在 50ms 以内。

### Q2: 在 Android 上配置私人 DNS 提示“无法连接”怎么办？

**答**：请确认 853 端口已经在 VPS 防火墙（UFW/security group）中开放，且绑定的 SSL 证书不是自签证书（必须是公网 CA 签发）。

### Q3: 自建 DNS 和直接用 1.1.1.1 比，优势在哪？

**答**：三点：① 防劫持，运营商看不到你查了什么；② 广告拦截，服务端规则集全家设备生效，手机不用装去广告 App；③ 分流可控，国内域名走 223.5.5.5、国外走代理，延迟最优。代价是你要维护一台 VPS。

### Q4: 规则集里的 geosite-ads 多久更新一次？

**答**：配置里的 `update_interval: "1d"` 会每天自动拉取。广告域名更新快，保持自动更新即可，不用手动管。
