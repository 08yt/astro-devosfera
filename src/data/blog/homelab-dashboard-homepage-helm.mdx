随着 Homelab 中部署的微服务越来越多（软路由后台、PVE 节点、TrueNAS、Jellyfin、下载器、Git 仓库……），数十个不同的 IP、端口与二级域名让浏览器书签栏杂乱不堪。

早期的导航工具（如 Homer、Heimdall）往往只是静态超链接的集合。

而在 2026 年，基于 Next.js 与极简 YAML 声明式配置的 **Homepage** 凭借其杀手级特性——**服务小组件 (Service Widgets)**，让导航面板进化成了能够通过 API 实时感知各服务状态的家庭中控大屏！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **动态 API 小组件**：按钮不仅是链接，更直接显示 PVE 集群 CPU/内存负载、qBittorrent 实时上下行网速、Jellyfin 当前在线观影人数与 AdGuard 今日拦截率。
> - **零重构热重载**：所有配置采用声明式 YAML（`services.yaml`、`widgets.yaml`、`settings.yaml`），修改保存后浏览器毫秒级无感热刷新，无需重启容器。
> - **安全避坑**：禁止直接将读写 `/var/run/docker.sock` 挂给容器；推荐使用只读 `:ro` 或 `docker-socket-proxy` 限制只读 API。

## 🛠️ 2026 生产级 Docker Compose 部署

在服务器创建 `compose.yaml`：

```yaml
services:
  homepage:
    image: ghcr.io/gethomepage/homepage:latest
    container_name: homelab_homepage
    restart: unless-stopped
    ports:
      - "3000:3000"
    volumes:
      - ./config:/app/config
      - /var/run/docker.sock:/var/run/docker.sock:ro # 只读安全挂载
    environment:
      - LOG_LEVEL=info
```

启动面板：`docker compose up -d`。

## 🚀 核心配置实战：定义动态小组件

在 `./config/services.yaml` 中配置带有实时状态小部件的组件：

```yaml
- 基础架构核心:
    - Proxmox VE:
        icon: proxmox
        href: https://pve.internal.lan:8006
        description: PVE 虚拟化母鸡
        widget:
          type: proxmox
          url: https://192.168.1.100:8006
          username: api_user@pve
          password: your_secret_password
          node: pve

- 媒体与下载:
    - Jellyfin:
        icon: jellyfin
        href: https://movie.internal.lan
        description: 私人 4K 影音中心
        widget:
          type: jellyfin
          url: http://192.168.1.100:8096
          key: your_jellyfin_api_key

    - qBittorrent:
        icon: qbittorrent
        href: http://192.168.1.100:8080
        description: PT/BT 下载机
        widget:
          type: qbittorrent
          url: http://192.168.1.100:8080
          username: admin
          password: your_password
```

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 如何将 Homepage 映射至外网并保障安全？

**答**：强烈建议不要直接将 3000 端口映射公网；配合 **Cloudflare Tunnel + Zero Trust Access** 或自建 **Authentik SSO**，在外网访问 Homepage 时强制验证 GitHub 或 Google 身份鉴权。

### Q2: 部署外网访问导航站推荐哪家海外 VPS 搭建反向代理？

**答**：在 **DMIT** 或 **搬瓦工** 的 **中国电信 CN2 GIA** 或 **联通 AS9929** 专线 VPS 上配置反向代理，外网回源家庭内网 Homepage 仪表盘秒级加载。选购参考见 [《2026 国外 VPS 选购指南》](/posts/vps-buying-guide-2026/)。
