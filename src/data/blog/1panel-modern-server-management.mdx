在云服务器日益普及的今天，几十元就能拥有一台独立 VPS。然而并非每个极客都有精力去死磕复杂的 Linux 命令行与 Nginx 规则。

老牌宝塔面板曾经一统天下，但随之而来的臃肿、强制手机号绑定和广告令很多极客疲惫不堪。

基于 Go 语言与 Docker 容器化底层构建的现代化开源面板 ── **1Panel**，凭借干净纯粹的架构与丰富的应用商店，成为了当前服务器运维的首选！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **Docker 原生架构**：所有应用（WordPress、MySQL、Redis、Alist 等）均以独立容器运行，卸载时 0 残留，绝不污染宿主机系统环境。
> - **100% 开源无捆绑**：无需绑定手机号，无任何商业广告插播，系统轻量仅耗 ~30MB 内存。
> - **一键自动化**：内置免费 Let's Encrypt / ACME 证书自动申请与续期、全量数据定时备份至对象存储（S3/WebDAV）。

## 🛠️ 一行命令极速安装 1Panel

使用 `root` 权限登录 VPS，执行官方一键脚本：

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && sudo bash quick_start.sh
```

安装完成后，终端会输出后台访问地址（如 `http://你的IP:目标端口/安全入口`）及初始管理员账号密码。
