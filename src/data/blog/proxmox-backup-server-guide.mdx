在 Homelab 折腾之路中，“数据无价，谨慎操作”是每一个踩过坑的极客的血泪教训。

很多使用 Proxmox VE (PVE) 的朋友习惯使用系统自带的 `vzdump` 备份功能，将 VM 打包成 `vma.zst` 文件存入外接硬盘。

这种传统方案是**全量备份**：即使 50GB 的虚拟机今天只修改了一个 2KB 配置文件，每次定时备份依然需要耗费数十分钟完整读取并写入 50GB 镜像，极易挤爆存储空间且严重损耗 SSD 寿命。

Proxmox 官方推出的企业级开源备份基座——**Proxmox Backup Server (PBS 3)**，凭借基于数据块（Chunk-based）的极速增量、跨容器全局去重与单文件在线提取，成为了虚拟化备份的终极神作！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
> - **秒级块级增量**：除首次全量外，后续备份仅传输变更的数据块（通常几秒钟内完成），对宿主机与正在运行的业务几乎 0 性能感知。
> - **恐怖的全局去重 (Deduplication)**：对于安装相同操作系统（如 10 个 Debian 容器）的虚拟机集群，重复的系统公共文件仅在 PBS 磁盘中保存一份，存储节省率高达 80%~90%。
> - **单文件秒级检索恢复 (File-level Restore)**：误删某个系统配置文件时，无需还原整台 100GB 的虚拟机，直接在网页控制台浏览备份镜像文件系统并下载该单文件。
> - **客户端端到端强加密**：数据在离开 PVE 节点前已使用 AES-GCM-256 加密，备份服务器即便被窃也无法窥探任何数据。

## 📊 2026 备份方案对比：传统 VZDump vs PBS

| 评测维度 | PVE 原生 VZDump 打包 | 官方 Proxmox Backup Server (PBS 3) |
| :--- | :--- | :--- |
| **备份机制** | 全量打包装入 `.vma` 归档 | 🏆 **4MB 数据块切片 (Chunk-based 增量)** |
| **二次备份耗时** | 10~30 分钟 (取决于全盘容量) | 🏆 **5~15 秒 (仅扫描变更脏块)** |
| **全局数据去重** | 无（每次完整复制） | 🏆 **跨所有 VM/CT 全局 SHA-256 块去重** |
| **细粒度文件提取** | 不支持（必须整机恢复） | 🏆 **支持网页在线单文件解压下载** |
| **保留与修剪策略** | 仅支持保留最后 N 份 | 🏆 **支持 GFS 保留策略 (日/周/月/年动态修剪)** |

## 🛠️ PBS 与 PVE 联动核心配置流程

### 1. PBS 端创建受限用户与 Datastore
在 PBS 控制台创建独立数据存储目录 `Datastore`，并在 **Access Control** 创建专属备份账户（如 `pve_agent@pbs`），授予 `Datastore.Backup` 与 `Datastore.Audit` 权限，保障最小特权原则。

### 2. 在 PVE 数据中心添加 PBS 存储
进入 PVE 的 **数据中心 -> 存储 -> 添加 -> Proxmox Backup Server**：
- **服务器**：输入 PBS 局域网 IP（如 `192.168.1.101`）。
- **用户名**：`pve_agent@pbs` 及密码。
- **Datastore**：填入 PBS 上的存储池名称。
- **指纹 (Fingerprint)**：填入 PBS Dashboard 提供的 SHA-256 证书指纹（保障 TLS 防中间人攻击）。

### 3. 配置智能保留策略 (Prune Schedule)
在 PVE 备份计划中配置生产级 GFS 修剪规则：
- `Keep Last`: 3（保留最近 3 次）
- `Keep Daily`: 7（保留最近 7 天）
- `Keep Weekly`: 4（保留最近 4 周）
- `Keep Monthly`: 6（保留最近 6 个月）
PBS 每天夜间自动执行 Garbage Collection（垃圾回收）释放被删除的冗余数据块！

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: PBS 可以作为虚拟机安装在 PVE 宿主机内部吗？
**答**：可以，但必须将一块独立的物理硬盘直通给 PBS 虚拟机作为专属 Datastore；最佳灾难恢复实践依然是物理隔离部署（部署在局域网另一台独立旧小主机或 NAS 上）。

### Q2: 践行 3-2-1 备份原则将 PBS 异地同步推荐哪家海外 VPS？
**答**：利用 PBS 的 `Remote Sync` 功能将本地备份加密同步到异地云端，在 **DMIT** 或 **搬瓦工** 的 **中国电信 CN2 GIA** 或 **联通 AS9929** 专线 VPS 上部署云端 PBS 节点，跨国增量传输稳定跑满带宽。选购参考见 [《2026 国外 VPS 选购指南》](/posts/vps-buying-guide-2026/)。
