很多刚入坑 **Sing-box** 的玩家在开启“科学上网”后，常遇到痛点：国内手机银行提示风控闪退、微信视频通话频繁卡死断联、国服游戏延迟暴涨。

这些问题的根源在于客户端没有做好 **分应用代理（Per-App Proxy）** 与 **进程黑白名单分流（Process Name Routing）**。

今天我们将手把手调优 Sing-box 的 **TUN（虚拟网卡）模式**，打造“国内直连无感、国外极速冲浪”的全天候上网体验！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **Android (SFA)**：开启 `App Bypass`，将微信、支付宝、网银及国服手游勾选为 `Bypass Selected` 物理直连。
> - **PC 桌面端**：在 `route.rules` 顶部通过 `"process_name": ["WeChat.exe", "QQ.exe"]` 强制直连，`"process_name": ["Telegram.exe", "Discord.exe"]` 强制代理。
> - **微信通话断联**：在直连规则最上方配置私有 IP 豁免与国内公共 DNS，避免 UDP 打洞信令被假 IP (Fake-IP) 劫持。

## 🛠️ PC 桌面端 (Windows/macOS) 进程分流配置模板

在 Sing-box 客户端 `config.json` 的 `route.rules` 模块中配置：

```json
{
  "route": {
    "rules": [
      {
        "process_name": [
          "WeChat.exe",
          "WeChat",
          "QQ.exe",
          "AliPay.exe",
          "League of Legends.exe"
        ],
        "outbound": "direct"
      },
      {
        "process_name": ["Discord.exe", "Telegram.exe", "Spotify.exe"],
        "outbound": "proxy"
      },
      {
        "rule_set": ["geosite-cn", "geoip-cn"],
        "outbound": "direct"
      }
    ],
    "final": "proxy"
  }
}
```

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 开启 TUN 模式后 Windows 自带应用商店 (UWP) 无法连网怎么解决？

**答**：在 Sing-box `inbounds` 的 `tun` 模块中将 `"stack"` 设为 `"system"` 或 `"mixed"`，并使用 Windows Loopback 豁免工具放行 UWP 应用。

### Q2: 为什么优质专线机场比自建节点在分流体验上更稳定？

**答**：优质商业专线机场内置成熟的全球流媒体与国内直连分流规则，搭配 **中国电信 CN2 GIA** 或 **联通 AS9929** 专线，推荐阅读 [《“饿饭CC云”深度评测》](/posts/efan-cc-cloud-review/)。
