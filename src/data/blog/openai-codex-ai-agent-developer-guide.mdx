在过去数年中，AI 辅助编程经历了翻天覆地的代际跃迁：
从早期按 Tab 键“挤牙膏”式补全单行代码的 GitHub Copilot，到能够感知全局项目上下文的 Cursor，再到 2026 年全面爆发的**自主编程智能体（Autonomous Coding Agent）**。

以 **OpenAI Codex** 及其衍生的 Agent 框架为代表，AI 已经脱离了单纯的“文本预测器”定位，进化为能够独立探索目录、阅读项目文档、规划任务清单、调用终端并自我修复 Bug 的“数字全栈工程师”！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
> - **Coding Agent 核心闭环 (ReAct)**：采用“思考 (Think) -> 工具调用 (Act: 读文件/跑测试/写代码) -> 环境观察 (Observe) -> 自主纠错 (Iterate)”工作流，彻底代替手动复制粘贴。
> - **`AGENTS.md` 行为宪法**：在项目根目录维护声明式开发守则与架构规范，智能体在启动时强制加载上下文，减少 70%+ 的代码幻觉与违规重构。
> - **沙箱安全防线**：严格实行 Standard Sandbox Mode（安全沙箱拦截未授权外网访问与高危系统指令），配合 Git 检查点随时回滚，保障宿主机绝对安全。

## 🛠️ 项目根目录规范：编写一份完美的 `AGENTS.md`

在 2026 年的现代工程实践中，在项目根目录编写 `AGENTS.md` 是约束 AI 行为准则的事实标准：

```markdown
# 🤖 项目智能体开发规范 (Agent Constitution)

## 🛠️ 技术栈与架构约束
- **核心框架**：Astro 5 + Tailwind CSS v4。
- **状态管理**：原生 React Context / Nanostores。
- **文件规范**：文章一律存放在 `src/data/blog/`，命名采用 `kebab-case.mdx`。

## ⚠️ 核心行为准则
1. **计划优先**：修改核心代码前必须输出 Implementation Plan，说明将改动的具体文件与设计理由。
2. **测试与类型自检**：完成代码修改后，必须主动执行 `pnpm exec astro check` 确保 0 报错。
3. **保留文档完整性**：严禁擅自删减已有版权声明、JSDoc 注释或作者元数据。
```

## 🛡️ 智能体时代的沙箱防御三大纪律

1. **终端沙箱隔离 (Sandbox Isolation)**：
   - 默认禁止智能体无感知发起未授权的公网请求；避免将敏感系统的管理权限暴露给未受控的环境。
2. **Git 快速检查点 (Checkpoints)**：
   - 在交由 Agent 执行复杂重构前，务必执行一次快照提交：`git add . && git commit -m "checkpoint before agent"`；一旦重构逻辑偏离，执行 `git reset --hard` 秒级复原。
3. **敏感凭据脱敏 (`.env` 隔离)**：
   - 确保所有敏感的 API Key 与数据库密码存放在 `.env.local` 且已被 `.gitignore` 忽略，严防敏感数据被读取纳入上下文。
