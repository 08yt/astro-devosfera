很多朋友为了追求低延迟和便宜价格，往往会买一些机房广播 IP 的廉价 VPS（如 CloudCone 或 RackNerd）来搭建节点。

但这会带来一个极其痛苦的问题：在成功翻墙后，当你打开 Netflix，由于机房 IP 被判定为数据中心，只能看极其有限的自制剧；当你打开 ChatGPT 或者 Claude 时，直接弹出一句高冷的 **"Access denied"** 或提示所在地区不可用。

在 **Sing-box** 中，有最免费优雅的解法：利用 Sing-box 原生支持的 **WireGuard 出站协议**，将特定网站的流量“二次转发”给 Cloudflare 免费且干净的 WARP 节点出网！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **链式代理逻辑**：普通流量从 VPS 原生 IP 直连出网（速度快）；ChatGPT、Claude、Netflix 流量经由 Sing-box 的 WireGuard 出站送入 Cloudflare WARP 节点。
> - **2026 语法更正**：路由匹配使用二进制 `.srs` 规则集 (`rule_set: ["geosite-openai", "geosite-netflix"]`)。
> - **关键配置**：WireGuard 必须显式指定 `"mtu": 1280`，防止包体积超标引发 UDP 丢包断流。

## 🔗 核心原理解析：链式代理 (Chain Routing)

当你的客户端连上海外 VPS 的 Sing-box 时，Sing-box 根据规则在 VPS 内部建立一条通往 Cloudflare WARP 节点的 WireGuard 加密隧道：

- **普通流量（看 YouTube/查资料）**：从 VPS 本地公网出口直接发出去，跑满服务器的原生物理宽带。
- **AI 与流媒体流量（ChatGPT/Claude/Netflix）**：通过 WireGuard 转发至 WARP 的 IP 库出去。由于 Cloudflare 节点的广谱合规性，能够无缝绕过 OpenAI 的数据中心风控封锁。

---

## 🛠️ 第一步：提取 WARP 的 WireGuard 账户参数

你可以在任何安装了 Python 的终端上使用开源工具（如 `warp-reg`）生成 WARP 的 WireGuard 参数：

```json
{
  "private_key": "your-warp-private-key-here",
  "peer_public_key": "bmXOC+F1FxEMF9...",
  "local_address": [
    "172.16.0.2/32",
    "2606:4700:110:86ad:70ee:1cc2:a7d7:fb8/128"
  ],
  "reserved": [0, 0, 0]
}
```

---

## 🚀 第二步：在 Sing-box 服务端配置 WireGuard 出站

打开 VPS 上的 Sing-box 服务端 `config.json`，在 `outbounds` 中新增一个 `warp-out` 出站：

```json
"outbounds": [
  {
    "type": "direct",
    "tag": "direct"
  },
  {
    "type": "wireguard",
    "tag": "warp-out",
    "server": "engage.cloudflareclient.com",
    "server_port": 2408,
    "local_address": [
      "172.16.0.2/32",
      "2606:4700:110:86ad:70ee:1cc2:a7d7:fb8/128"
    ],
    "private_key": "your-warp-private-key-here",
    "peer_public_key": "bmXOC+F1FxEMF9...",
    "reserved": [0, 0, 0],
    "mtu": 1280
  }
]
```

---

## 🔀 第三步：编写精准路由规则

在服务端的 `route` 模块写上分发规则，仅让 OpenAI 与 Netflix 走 WARP 解锁：

```json
"route": {
  "rules": [
    {
      "rule_set": ["geosite-openai", "geosite-netflix"],
      "outbound": "warp-out"
    }
  ],
  "final": "direct"
}
```

重启服务端 Sing-box 进程：

```bash
systemctl restart sing-box
```

此时，无需修改手机或电脑端的任何配置，网页端打开 ChatGPT 与 Netflix 即刻恢复原生解锁体验！

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 为什么要将 WireGuard 出站的 MTU 设置为 `1280`？

**答**：由于 WARP 数据包被封装在原本的 TCP/UDP 代理报文内部（嵌套头部），会导致默认 1500 字节的 MTU 超标引发网络分片丢包。设为 `1280` 能保证在跨国公网链路上 100% 传输顺畅。

### Q2: 开启 WARP 分流后，访问 ChatGPT 会降低响应速度吗？

**答**：对 API 的 JSON 交互和文字生成速度几乎毫无感知；仅针对流媒体大流量下载时相比原生 IP 会有少量延迟损耗，因此我们只针对特定的 AI/流媒体域名开启 WARP 分流。
