习惯了 Clash 或旧版 V2Ray 的朋友，初次看到 **Sing-box** 的规则分流模块时，都会被其核心创新所吸引 ── **Rule Set（规则集）**。

传统纯文本或 `.dat` 格式需占用上百兆内存并耗费数秒解析，而 Sing-box 引入的**二进制规则集（`.srs` 格式）**将其编译为高性能前缀树，内存开销直降 80%，匹配耗时低于 1ms。

今天我们将全面解析 Sing-box 规则集的远程更新、本地加载与命令行编译全流程！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **二进制格式**：统一采用 `"format": "binary"` 配合 `.srs` 文件，省内存、抗抖动、秒级启动。
> - **下载绕行铁律**：`remote` 规则集必须配置 `"download_detour": "proxy"`，确保 GitHub Raw 规则更新不受防火墙干扰。
> - **自动更新**：设置 `"update_interval": "1d"` 实现每日静默重载，免去人工维护。
> - **本地编译指令**：`sing-box rule-set compile source.json -o target.srs`。

---

## 🛠️ 1. 顶层 `rule_set` 声明与远程自动更新

在 Sing-box `config.json` 顶层进行声明：

```json
{
  "rule_set": [
    {
      "tag": "geosite-cn",
      "type": "remote",
      "format": "binary",
      "url": "https://raw.githubusercontent.com/SagerNet/sing-geosite/rule-set/geosite-cn.srs",
      "download_detour": "proxy",
      "update_interval": "1d"
    },
    {
      "tag": "geoip-cn",
      "type": "remote",
      "format": "binary",
      "url": "https://raw.githubusercontent.com/SagerNet/sing-geoip/rule-set/geoip-cn.srs",
      "download_detour": "proxy",
      "update_interval": "1d"
    }
  ]
}
```

## 🔀 2. 路由模块 `route.rules` 极简引用

在路由判断中直接通过标签引用规则集：

```json
{
  "route": {
    "rules": [
      {
        "rule_set": ["geosite-cn", "geoip-cn"],
        "outbound": "direct"
      }
    ],
    "final": "proxy"
  }
}
```
