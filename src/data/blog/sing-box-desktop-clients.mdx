## 💻 2026 桌面端主流 Sing-box 客户端对比与选型

在桌面电脑上，除了直接使用终端运行 `sing-box run -c config.json` 命令行外，强烈推荐使用 GUI 图形界面应用以获得极其便捷的体验：

### 1. Mihomo Party (全平台强推 🏆)

- **核心特点**：2026 年风靡社区的现代桌面客户端，拥有极其惊艳的 UI 交互，原生支持 Sing-box 与 Mihomo 双内核无缝切换。
- **推荐人群**：追求极致颜值、喜欢优雅节点分组与抓包日志的用户。

### 2. Sing-box GUI / Desktop (官方推荐 官方)

- **核心特点**：由 SagerNet 官方采用 Flutter 框架打造，体积小巧、绿色无广告，对 Sing-box 最新内核特性的支持最及时。
- **推荐人群**：追求纯粹原生体验、轻量高效的极客玩家。

### 3. Hiddify Next (跨平台零门槛 🚀)

- **核心特点**：完全开源且跨全平台（Windows, macOS, Linux, Android, iOS），自动识别粘贴板的 Sing-box 订阅链接并一键开启 TUN。
- **推荐人群**：小白新手用户、讨厌繁琐配置的朋友。

## ⚙️ 核心使用要点与 TUN 增强模式配置

### 1. 订阅一键导入

启动客户端后，选择 **Profiles (配置管理)** -> **Add Profile / Remote URL**，粘贴服务商给出的远程 Sing-box 订阅链接。点击保存并拉取配置。

### 2. 必须开启 TUN 模式 (Virtual Network Adapter)

普通的系统 HTTP 代理无法接管终端命令行（如 `git`、`npm`、`curl`）以及绝大多数无代理设置入口的应用。

在客户端设置中找到并勾选 **"Enable TUN Mode" (开启 TUN 模式)**：

- **Windows 端**：会安装一个 TAP/TUN 虚拟网卡，建议开启 `auto_detect_interface`。
- **macOS 端**：会提示授权安装系统 Network Extension (网络扩展)，授权后菜单栏图标变绿即可全盘接管流量。

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 开启 TUN 模式后，局域网共享或 NAS 打印机连不上了怎么办？

**答**：请在客户端设置中检查 `Bypass LAN`（绕过局域网）选项是否勾选。Sing-box 默认在 `ip_cidr` 中将 `192.168.0.0/16` 与 `10.0.0.0/8` 设为 `direct` 放行，可防止内网回源受阻。

### Q2: Sing-box GUI 提示 `permission denied` 或无法拉起 TUN 网卡怎么办？

**答**：在 Windows 上，请右键点击客户端图标并选择 **“以管理员身份运行”**；在 macOS 上，请前往“系统设置 -> 隐私与安全性 -> 代理与网络扩展”中予以授权允许。
