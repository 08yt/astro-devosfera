在软件开发与自动化运维中，Git 版本控制（Version Control）是极客的核心基础设施。

然而将所有商业项目、配置文件和私有脚本存放在 GitHub / Gitee 等公共云端，常面临账号被封禁、企业审核或数据安全隐私泄露的隐患。

**Gitea（及社区分支 Forgejo）** 基于 Go 语言构建，拥有类似 GitHub 的绝美 UI 与完整的 CI/CD（Gitea Actions），且常驻内存仅需 ~30MB，是一台廉价小鸡即可承载的私有代码云中心！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **轻量高效碾压 GitLab**：GitLab 需动辄 4GB+ 内存，而 Gitea 仅需单核 512MB VPS 即可跑满几十人团队并发。
> - **GitHub 级使用体验**：完美复刻 GitHub 的 Issues、Pull Requests、Release、Wiki 与 Organizations 组织架构。
> - **Gitea Actions 原生 CI/CD**：100% 兼容 GitHub Actions 的 YAML 工作流语法，轻松实现代码提交后自动触发编译与部署。

## 🛠️ 2026 生产级 Docker Compose 部署配置

在服务器创建 `compose.yaml`：

```yaml
services:
  gitea:
    image: gitea/gitea:latest
    container_name: gitea
    restart: unless-stopped
    environment:
      - USER_UID=1000
      - USER_GID=1000
      - GITEA__database__DB_TYPE=sqlite3
      - GITEA__server__DOMAIN=git.yourdomain.com
      - GITEA__server__SSH_PORT=222
      - GITEA__server__ROOT_URL=https://git.yourdomain.com/
    volumes:
      - ./data:/data
      - /etc/timezone:/etc/timezone:ro
      - /etc/localtime:/etc/localtime:ro
    ports:
      - "3000:3000" # Web 管理界面
      - "222:22" # Git SSH 提交端口
```

启动服务：`docker compose up -d`。

## 🚀 初始化与常用操作

1. 浏览器访问 `http://你的IP:3000`，进入初始化安装向导。
2. 数据库类型选择默认的 **SQLite3**（无需额外部署 MySQL），直接点击安装。
3. 注册的第一个用户将自动获得超级管理员权限。
4. 本地终端通过 SSH 提交代码：
   ```bash
   git remote add origin ssh://git@git.yourdomain.com:222/username/repo.git
   git push -u origin main
   ```

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: Gitea 如何实现数据全量自动异地备份？

**答**：可以使用 Gitea 内置的 `docker exec -it gitea su git -c "gitea dump"` 命令将全库打包为 zip，并通过 Rclone/Ansible 定时同步到对象存储。

### Q2: 部署私有 Git 服务推荐使用哪种海外 VPS？

**答**：在自建 **DMIT** 或 **搬瓦工** 等拥有 **中国电信 CN2 GIA** 或 **联通 AS9929** 专线 VPS 上，跨国 `git push` 和 `git clone` 能获得毫秒级极低延迟。选购参考见 [《2026 国外 VPS 选购指南》](/posts/vps-buying-guide-2026/)。
