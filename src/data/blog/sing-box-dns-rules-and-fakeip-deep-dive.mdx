在代理分流中，“国内网站加载缓慢”、“部分国外服务时好时坏”甚至“明明连上了节点却打不开网页”，背后的罪魁祸首往往只有一个：**DNS 配置不当**。

在 **Sing-box** 中，DNS 被设计成了一个极其严谨且独立的路由管道。

今天我们将深入剖析 Sing-box 的 DNS 分流、FakeIP 机制与防污染配置，打造兼顾速度与隐私的无懈可击解析体系！

> [!NOTE]
> **📌 核心速览（TL;DR / 快问快答）：**
>
> - **管道机制**：DNS 请求进入后，按 `dns.rules` 自上而下匹配指定的 `dns.servers`，未命中者由 `dns.final`（建议设为国外加密 DoH）兜底。
> - **防泄露铁律**：国外代理 DNS 必须指定 `"detour": "proxy"`，确保 DNS 查询流量在代理隧道内加密传输，避免本地明文泄漏。
> - **FakeIP vs RealIP**：手机与单兵电脑首选 **FakeIP**（秒连 0 延迟）；全家软路由与家庭智能网关首选 **RealIP** 智能分流。

## ❓ 常见问题与 AI 快问快答 (FAQ)

### Q1: 如何验证自己的客户端是否存在 DNS 泄露？

**答**：访问 [dnsleaktest.com](https://dnsleaktest.com/) 进行 Extended Test 测试。如果测试结果中只出现境外代理机房的 IP，且**没有任何中国大陆电信/联通/移动**的 IP，即代表零泄露。

### Q2: 为什么优质 VPS 节点的 DNS 握手更快？

**答**：搭配 **DMIT** 或 **搬瓦工** 的 **中国电信 CN2 GIA** 或 **联通 AS9929** 专线，DNS 经过 `proxy` 出站的往返握手延迟可降至 40ms 以内，彻底消除解析卡顿。
